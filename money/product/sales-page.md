# 📦 1인 자동화 스타터 킷 — 판매 페이지 (Gumroad / 크몽 전자책용)

> 그대로 복사해서 Gumroad 상품 설명 또는 크몽 전자책 소개에 붙여넣으세요.

---

## 상품명
**하루 5분 세팅으로 끝내는 "1인 자동화 스타터 킷" — 코딩 몰라도 OK**

## 한 줄 소개
매일 아침 할 일이 슬랙으로 자동으로 뜨고, 반복 업무가 알아서 돌아가는 자동화 세트.
개발자가 실제로 쓰는 스크립트를 **복붙 + 설정만** 하면 바로 작동합니다.

## 가격
- **₩19,000** (얼리버드 ₩12,000)
- 업셀: 1:1 설치 도움 30분 = ₩30,000

---

## 이런 분께 (문제)
- "매일 똑같은 알림 보내고, 똑같은 정리하는 거 지겹다"
- "자동화하고 싶은데 개발은 못 하고, 노코드 툴은 월 구독료가 부담"
- "GPT한테 물어봐도 코드가 안 돌아가서 포기했다"

## 킷 구성 (무엇을 받나)
| 파일 | 내용 |
|------|------|
| `daily_goals` | 매일 정해진 시간에 **할 일 목록을 슬랙 DM으로 자동 발송**. 윈도우 예약 작업까지 자동 등록 |
| `slackbot` | 슬랙 자동응답/알림 봇 기본 골격 (원하는 대로 확장) |
| **설치 가이드 PDF** | 스크린샷 따라 하면 끝. 슬랙 토큰 발급 → 설정 → 예약 등록 전 과정 |
| **커스터마이징 치트시트** | "이 줄만 바꾸면 카톡/이메일로도 보낼 수 있어요" 형식의 실전 팁 |

## 왜 이게 다른가 (차별점)
- 이론서가 아니라 **실제로 돌아가는 코드**. 다운받아서 바로 실행.
- 개발자가 자기가 쓰려고 만든 걸 정리한 것 → 군더더기 없음.
- 30일 안에 안 돌아가면 **전액 환불**.

## 후기 자리 (첫 구매자에게 무료로 주고 후기 받기)
> ⭐⭐⭐⭐⭐ "진짜 5분 만에 슬랙 알림 세팅됨. 매일 까먹던 루틴이 자동으로 와요." — (구매자 후기 넣을 자리)

## FAQ
**Q. 개발 몰라도 되나요?** → 네. 복사·붙여넣기와 클릭만 하면 됩니다. 가이드에 스크린샷 전부 있습니다.
**Q. 맥에서도 되나요?** → 스크립트는 파이썬 기반이라 가능. 예약 등록만 맥 방식(cron) 안내가 필요 — 문의 주시면 도와드립니다.
**Q. 슬랙 말고 카톡으로도?** → 치트시트에 웹훅 바꾸는 법 포함.
