# 1인 자동화 스타터 킷 — 상품 패키징 안내

이 상품의 실제 파일은 저장소 루트에 이미 있습니다:

- `../../daily_goals/` — 매일 할 일 슬랙 자동 발송 (핵심 상품)
- `../../slackbot/` — 슬랙 봇 골격

## 판매용 zip 만드는 법 (배포 전 1회)

1. 아래 두 폴더를 복사해 `starter-kit/` 임시 폴더에 모은다
   - `daily_goals/` (단, `filter_stderr.log` 등 개인 로그·토큰은 제거)
   - `slackbot/` (`__pycache__` 제거, `bot.py` 안의 **실제 토큰/키는 반드시 삭제**하고 `YOUR_TOKEN_HERE` 로 치환)
2. 설치 가이드 PDF 추가 (아래 목차대로 작성 → anthropic pdf 스킬로 생성 가능)
3. `starter-kit.zip` 으로 압축 → Gumroad/크몽에 업로드

> ⚠️ 중요: 배포 전 **본인의 슬랙 토큰·웹훅·비밀번호가 코드에 남아있지 않은지** 반드시 확인.
> 토큰이 노출되면 남이 당신 슬랙에 접근할 수 있습니다.

## 설치 가이드 PDF 목차 (작성용)

1. 이 킷으로 뭘 할 수 있나 (30초 데모 스샷)
2. 준비물: 파이썬 설치, 슬랙 워크스페이스
3. 슬랙 봇 토큰 발급 (스크린샷 5장)
4. 설정 파일에 토큰 넣기 (딱 이 한 줄)
5. 실행 테스트
6. 매일 자동 실행 예약 걸기 (윈도우 작업 스케줄러)
7. 커스터마이징: 메시지 내용·시간 바꾸기
8. 문제 해결 FAQ

준비되면 "설치 가이드 PDF 만들어줘" 라고 하면 pdf 스킬로 만들어드립니다.
