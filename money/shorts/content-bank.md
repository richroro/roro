# 🎬 숏폼 대본 뱅크 15선 — "1인 자동화 / 생산성" 채널

> 니치: 개발·자동화 못 하는 사람에게 "이렇게 편해질 수 있다"를 보여주는 채널.
> 포맷: 15~40초, 세로 9:16. 첫 2초 훅이 생명. `make-shorts` 스킬로 촬영 가능.
> 수익화: 조회수 광고 + 자동화 대행/스타터킷 유입(설명란 링크) + 협찬.

---

## 대본 공통 구조
1. **훅(0~2초)**: 스크롤 멈추게 하는 한 문장 (문제/충격/궁금증)
2. **본론(3~25초)**: 화면 시연 + 나레이션
3. **CTA(마지막)**: "저장해두세요 / 더 궁금하면 댓글 / 프로필 링크"

---

### 1. 매일 아침 할 일 자동 알림
- **훅**: "아직도 할 일 목록 직접 써요?"
- **본론**: 슬랙에 매일 아침 9시 할 일이 자동으로 뜨는 화면 시연. "이거 한 번 세팅하면 평생 자동이에요."
- **CTA**: "만드는 법 궁금하면 댓글 '자동'"
- **해시태그**: #생산성 #자동화 #직장인꿀팁 #슬랙

### 2. 반복작업 3가지 자동화
- **훅**: "이거 손으로 하면 하루 1시간 날려요"
- **본론**: 파일 이름 일괄 변경 / 엑셀 취합 / 폴더 정리 3개를 스크립트로 1초 처리.
- **CTA**: "당신 회사 반복업무 뭐예요? 댓글로"
- #엑셀 #직장인 #업무자동화

### 3. "월 300 버는 1인 자동화" 브이로그형
- **훅**: "개발 몰라도 자동화로 돈 버는 법"
- **본론**: 대행 서비스가 뭔지 30초 설명 + 실제 결과물 스샷.
- **CTA**: "부업 관심있으면 팔로우"
- #부업 #N잡 #프리랜서

### 4. 노코드 vs 코드 자동화 비교
- **훅**: "월 3만원 내는 자동화툴, 사실 공짜로 돼요"
- **본론**: 유료 노코드 툴 화면 → 같은 걸 무료 스크립트로.
- **CTA**: "돈 아끼는 꿀팁 더 → 팔로우"
- #돈아끼기 #자동화 #꿀팁

### 5. 슬랙봇 30초 만들기
- **훅**: "슬랙 자동응답 봇, 30초면 만들어요"
- **본론**: 봇이 특정 단어에 자동응답하는 시연.
- **CTA**: "코드 필요하면 프로필 링크"
- #슬랙 #봇 #개발

### 6. 게임도 코딩으로 (자기 게임 홍보)
- **훅**: "제가 만든 축구 게임인데 CPU가 생각보다 셈"
- **본론**: 미니 축구 게임 플레이 화면.
- **CTA**: "해보고 싶으면 프로필 링크"
- #인디게임 #코딩 #웹게임

### 7. 웹캠 필터 만들기
- **훅**: "노트북 웹캠에 실시간 캐릭터 필터 씌우기"
- **본론**: face_character_filter 실행 화면.
- **CTA**: "만드는 법 원하면 댓글"
- #파이썬 #코딩 #필터

### 8. "이 앱 대신 스크립트 쓰세요"
- **훅**: "돈 내고 쓰던 이 기능, 코드 5줄이면 끝"
- **본론**: 흔한 유료 기능 하나를 짧은 코드로 대체.
- #개발 #꿀팁 #생산성

### 9. 아침 루틴 자동화
- **훅**: "제 하루는 자동으로 시작돼요"
- **본론**: 알림·날씨·할일이 아침에 자동으로 뜨는 대시보드.
- #루틴 #갓생 #자동화

### 10. 초보자용 파이썬 첫 자동화
- **훅**: "파이썬 배운 첫날 이거부터 만드세요"
- **본론**: 5줄짜리 파일정리 스크립트.
- **CTA**: "코드 댓글로 드림"
- #파이썬독학 #코딩입문

### 11. 실수 리메이크 (알고리즘 잘 먹힘)
- **훅**: "자동화하다 회사 파일 다 날릴 뻔한 썰"
- **본론**: 백업 안 하고 스크립트 돌린 실수담 + 교훈.
- #개발자 #썰 #직장

### 12. Before / After
- **훅**: "자동화 전 vs 후"
- **본론**: 수동 30분 → 자동 3초. 스톱워치로 비교.
- #비교 #생산성

### 13. 무료로 쓸 수 있는 자동화 도구 3개
- **훅**: "이거 무료인 거 아는 사람 별로 없음"
- **본론**: 도구 3개 빠르게 소개.
- #무료 #꿀팁 #추천

### 14. 구독자 사연 자동화 해결
- **훅**: "댓글로 받은 반복업무 자동화해봄"
- **본론**: 시청자 요청 업무를 실제로 자동화하는 과정. (참여형 → 떡상 소재)
- #자동화 #신청받음

### 15. "이번 달 부업 수익 공개"
- **훅**: "자동화 부업 한 달 결과"
- **본론**: 솔직한 수익/시간 공개 (숫자 있으면 신뢰↑).
- **CTA**: "따라 하고 싶으면 팔로우"
- #부업수익 #N잡 #투명공개
