# 🤖 자동화 대행 서비스 — 영업 킷

> 당신의 무기: 이미 만든 **daily_goals(슬랙 자동 발송)**, **slackbot**, 웹캠 필터, 게임.
> 소상공인·1인기업은 이런 걸 만들 줄 모른다. 그들의 반복 업무를 없애주고 돈을 받는다.

---

## 서비스 메뉴 & 가격표 (크몽/숨고 그대로 등록)

| 패키지 | 내용 | 가격 | 작업기간 |
|--------|------|------|---------|
| **BASIC** 반복작업 자동화 | 엑셀 정리·파일 이름 변경·데이터 취합 등 반복업무 1건 자동화 스크립트 | **7만원** | 2일 |
| **STANDARD** 알림봇 구축 | 슬랙/카톡/이메일 자동 알림봇 (예: 매일 할일, 매출 리포트, 예약 알림) | **25만원** | 4일 |
| **PRO** 업무 파이프라인 | 여러 툴 연결 자동화 (구글시트↔슬랙↔이메일), 스케줄 실행까지 세팅 | **50만원** | 7일 |
| **정기 관리** | 월 유지보수 + 수정 요청 대응 | **월 15만원** | 구독 |

> 💡 300만원 계산: PRO 3건(150만) + STANDARD 4건(100만) + 정기관리 3곳(45만) = **295만원/월**

---

## 타겟 고객 (누구에게 팔까)

- **동네 학원·병원·미용실** → 예약/노쇼 알림 자동화
- **쇼핑몰 셀러** → 주문 취합, 재고 알림, CS 템플릿 자동화
- **1인 유튜버/블로거** → 업로드 스케줄 알림, 댓글 취합
- **소규모 스타트업** → 슬랙 데일리 리포트, 온보딩 자동화

## 콜드 DM 템플릿 (인스타/이메일)

**버전 A — 문제 제기형**
```
안녕하세요 OO님, [업종] 운영하시는 거 보고 연락드려요.
혹시 매일 반복하는 업무(예약 확인, 매출 정리, 알림 보내기) 때문에
시간 뺏기고 계신다면 그거 자동화로 없애드립니다.
간단한 건 하루 만에 끝나고, 첫 상담은 무료예요.
관심 있으시면 답장 주세요 🙂
```

**버전 B — 결과 미끼형**
```
"매일 아침 할 일이 자동으로 슬랙에 뜨게" 만드는 봇,
제가 실제로 쓰고 있는데 저희 [업종] 고객분들이 제일 좋아하세요.
OO님 업무에도 이런 반복작업 없애드릴 수 있을 것 같아서요.
포트폴리오 보여드릴까요?
```

## 포트폴리오로 쓸 수 있는 것 (이미 있음!)

1. **daily_goals** — "매일 아침 할 일 자동 슬랙 발송" → STANDARD 실제 사례
2. **slackbot** — "슬랙 자동응답 봇" → 봇 구축 역량 증명
3. 스크린샷 2~3장 + 30초 시연 영상이면 충분

> 첫 상담 무료 → 문제 파악 → 견적 → 계약. 후기 1개만 받으면 눈덩이처럼 굴러간다.
