## 1장. 왜 지금 자동화인가 — 1인 사업가의 시간 전쟁

직원을 둔 회사는 업무를 "나눌" 수 있습니다. 하지만 1인 사업가와 프리랜서는 모든 역할을 혼자 감당해야 합니다. 문제는 이 구조가 **매출과 무관하게 시간을 갉아먹는다**는 점입니다.

일반적인 1인 사업가의 하루를 시간 단위로 쪼개보면 이렇습니다.

| 업무 유형 | 예시 | 주당 평균 소요 시간 |
|---|---|---|
| 핵심 업무 (돈이 되는 일) | 제품 제작, 컨설팅, 강의, 판매 | 15~20시간 |
| 커뮤니케이션 | 이메일, 카톡, DM 응대 | 8~10시간 |
| 문서/행정 | 견적서, 계약서, 세금계산서 | 5~7시간 |
| 콘텐츠 마케팅 | SNS, 블로그, 뉴스레터 | 6~8시간 |
| 고객 지원 | 문의 응대, FAQ 반복 답변 | 4~6시간 |

핵심 업무 외의 시간을 모두 더하면 주당 **23~31시간**입니다. 이는 정규직 한 명의 근무 시간과 맞먹습니다. 즉, 자동화를 하지 않는다는 것은 보이지 않는 직원 한 명의 월급을 그냥 시간으로 지불하고 있는 것과 같습니다.

**자동화의 목적은 "일을 없애는 것"이 아니라 "선택할 시간을 되찾는 것"**입니다. 반복 업무를 AI와 도구에 위임하면, 그 시간을 매출을 직접 만드는 활동—영업, 제품 개선, 관계 구축—에 쓸 수 있습니다.

이 책에서 다루는 자동화는 세 단계로 나뉩니다.

1. **대체(Replace)**: 사람이 하던 반복 작업을 AI가 대신 수행 (예: 이메일 초안 작성)
2. **보조(Assist)**: AI가 초안을 만들고 사람이 검토·수정 (예: 제안서 초안)
3. **연결(Connect)**: 여러 도구를 자동으로 이어 사람 개입 없이 흐르게 함 (예: 문의 접수 → 자동 분류 → 답변 초안 생성 → 알림)

책을 읽어가며 자신의 업무가 이 세 단계 중 어디에 해당하는지 표시해두세요. 9장의 로드맵에서 다시 활용합니다.

## 2장. 시작하기 전에: 나의 업무 자동화 지도 그리기

도구부터 배우기 전에 먼저 해야 할 일이 있습니다. **무엇을 자동화할지 파악하는 것**입니다. 많은 사람이 화려한 자동화 도구를 먼저 익히고 나서 "이걸로 뭘 하지?"라고 묻습니다. 순서가 바뀌면 시간을 두 번 씁니다.

### 자동화 우선순위 매트릭스

아래 표를 인쇄하거나 노트에 옮겨 그려보세요. 지난 2주간 했던 업무를 모두 적고, 두 가지 기준으로 채점합니다.

- **빈도**: 이 일을 얼마나 자주 하는가 (1~5점)
- **소모도**: 이 일이 얼마나 지루하거나 시간을 잡아먹는가 (1~5점)

두 점수를 곱해서 8점 이상인 업무부터 자동화 대상으로 선정합니다.

```
업무                     빈도   소모도   점수   자동화 단계
------------------------------------------------------
문의 이메일 답장          5      4       20     대체
견적서 작성                4      3       12     보조
SNS 게시물 작성            5      3       15     보조
회의록 정리                3      4       12     대체
세금계산서 발행            2      2        4     (보류)
고객 후기 요청 메일         3      2        6     (보류)
```

이 예시에서는 "문의 이메일 답장"과 "SNS 게시물 작성"이 최우선 자동화 대상이 됩니다. 이 책의 3장과 5장이 바로 이 두 업무를 다룹니다.

### 자동화하면 안 되는 것

모든 것을 자동화하려는 함정에 빠지지 마세요. 다음은 사람이 직접 해야 신뢰가 쌓이는 영역입니다.

- 고가 계약 전 첫 상담 (신뢰 형성이 핵심)
- 클레임·불만 고객 응대 (공감이 자동화되지 않음)
- 브랜드의 핵심 메시지와 톤 결정 (AI는 실행을, 방향은 사람이)

원칙은 이렇습니다: **"판단"은 사람이, "반복"은 AI가.**

## 3장. AI로 이메일·메시지 응대 자동화하기

이메일과 메시지 응대는 1인 사업가가 가장 많은 시간을 뺏기는 영역입니다. 완전 자동 발송이 아니라 **"AI 초안 + 사람 최종 확인"** 구조를 만드는 것이 핵심입니다. 이렇게 하면 속도는 빨라지고 실수 위험은 낮아집니다.

### 3단계 워크플로우

**1단계. 자주 오는 문의 유형 5~7개를 정리한다**
가격 문의, 일정 문의, 협업 제안, 환불 요청, 강의 신청 등으로 분류합니다.

**2단계. 유형별 답변 템플릿을 AI와 함께 만든다**
아래 프롬프트를 ChatGPT나 Claude에 입력해 나만의 톤으로 다듬습니다.

```
나는 [업종]을 운영하는 1인 사업가야.
아래는 자주 받는 문의 유형과 내가 원하는 답변 톤이야.

문의 유형: 가격 문의
원하는 톤: 친절하지만 전문적으로, 너무 길지 않게
포함할 정보: 가격 범위, 견적서 요청 방법, 상담 예약 링크

이 조건에 맞는 답장 템플릿을 3가지 버전(정중한 버전, 캐주얼한 버전, 짧은 버전)으로 만들어줘.
```

**3단계. 실제 문의가 오면 AI에게 "이 템플릿을 이 문의에 맞게 다듬어줘"라고 요청한다**

```
아래는 내 기본 답변 템플릿이야:
[템플릿 붙여넣기]

아래는 실제로 받은 문의야:
[고객 문의 내용 붙여넣기]

템플릿의 톤과 구조를 유지하면서, 이 문의의 구체적인 내용(이름, 요청사항)에
맞게 답장을 완성해줘.
```

이 구조의 장점은 **매번 처음부터 쓰지 않는다**는 것입니다. 템플릿이 뼈대를 잡아주고, AI는 문의 내용에 맞춰 살을 붙일 뿐입니다. 답장 작성 시간이 평균 8분에서 1~2분으로 줄어듭니다.

### 한 단계 더: 이메일 자동 분류

Gmail을 쓴다면 라벨과 필터를 조합해 문의 유형을 자동으로 태깅할 수 있습니다. "가격", "환불", "협업" 같은 키워드가 포함된 메일에 자동으로 라벨을 붙이면, 어떤 템플릿을 써야 할지 한눈에 파악됩니다. 8장에서 다룰 Zapier나 Make를 연결하면 이 분류 과정 자체도 AI가 판단하도록 만들 수 있습니다.

## 4장. 문서 작업 자동화: 제안서, 보고서, 계약서

문서 작업의 진짜 문제는 "작성"이 아니라 "매번 처음부터 구조를 잡는 것"입니다. 해결책은 **마스터 템플릿 + AI 채움 방식**입니다.

### 제안서 마스터 프롬프트

```
너는 [업종] 전문 제안서 작성을 돕는 어시스턴트야.
아래 정보를 바탕으로 제안서를 작성해줘.

[고객사/고객명]:
[프로젝트 목적]:
[제공할 서비스 범위]:
[예상 기간]:
[예상 비용 범위]:
[우리 강점 2~3가지]:

구조:
1. 인사말 및 문제 이해
2. 제안 개요
3. 진행 프로세스 (단계별)
4. 기대 효과
5. 비용 및 일정
6. 마무리 인사

톤: 전문적이되 딱딱하지 않게. 불필요한 미사여구는 빼줘.
```

이 프롬프트를 문서로 저장해두고, 새 제안서가 필요할 때마다 대괄호 안의 정보만 바꿔서 넣으면 됩니다. 초안 작성 시간이 1~2시간에서 10~15분으로 줄어듭니다.

### 회의록·통화 요약 자동화

녹음 앱이나 회의 도구(Zoom, 네이버 클로바노트 등)로 받아쓰기를 한 뒤, 아래 프롬프트로 정리합니다.

```
아래는 고객과의 미팅 녹취록이야.

[받아쓰기 텍스트 붙여넣기]

다음 형식으로 요약해줘:
- 논의 핵심 내용 (3~5줄)
- 고객이 요청한 사항 (체크리스트)
- 우리가 다음에 해야 할 액션 아이템 (담당자, 기한 포함)
- 후속 이메일 초안 (감사 인사 + 논의 내용 요약 + 다음 단계)
```

이렇게 하면 회의 후 30분씩 걸리던 정리 작업이 5분으로 줄어들고, 고객에게 보내는 후속 이메일까지 한 번에 나옵니다.

### 계약서·견적서는 신중하게

계약서는 AI가 초안을 만들되, **반드시 관련 법률 검토를 거치거나 표준 계약서 템플릿을 기반**으로 해야 합니다. AI가 만든 조항을 법적 효력이 있는 것처럼 그대로 사용하지 마세요. 견적서는 금액 계산 실수가 없도록 AI 초안 후 반드시 숫자를 직접 검산하는 습관을 들이세요.

## 5장. 콘텐츠 제작 자동화: 블로그·SNS·뉴스레터

콘텐츠는 매출에 직결되지만, 매일 새로운 아이디어를 짜내는 것은 소모적입니다. 핵심은 **"한 번의 원천 콘텐츠"를 "여러 형태로 재가공"**하는 구조입니다.

### 원 소스 멀티 유즈(OSMU) 워크플로우

1. 주 1회, 핵심 주제 하나로 블로그 글 1편 작성 (AI 초안 + 직접 검수)
2. 그 글을 기반으로 AI에게 SNS 게시물 3~5개, 뉴스레터 1편, 짧은 영상 스크립트 1개를 파생 생성 요청

```
아래는 내가 쓴 블로그 글이야.

[블로그 본문 붙여넣기]

이 글을 활용해서 다음을 만들어줘:
1. 인스타그램 카드뉴스용 문구 5장 분량 (한 장당 한 줄 핵심 메시지)
2. 스레드(X) 게시용 짧은 글 3개 버전
3. 이메일 뉴스레터용 소개 문단 (3~4문장, 클릭 유도 문구 포함)
4. 숏폼 영상 스크립트 (30초 분량, 훅-본문-CTA 구조)
```

이 방식으로 콘텐츠 하나를 만드는 데 걸리는 시간은 그대로지만, **산출물은 4~6배로 늘어납니다.**

### 콘텐츠 아이디어 고갈 방지 프롬프트

```
나는 [업종/타겟 고객]을 대상으로 콘텐츠를 만드는 사람이야.
다음 3가지 관점에서 이번 달 콘텐츠 주제 15개를 뽑아줘:
1. 고객이 자주 묻는 질문 기반
2. 업계의 흔한 오해를 바로잡는 내용
3. 우리 서비스/제품을 쓰기 전후 변화(비포&애프터) 사례

각 주제마다 어떤 형식(블로그/카드뉴스/영상)이 적합한지도 함께 표시해줘.
```

매주 콘텐츠 캘린더를 다시 짜는 대신, 월 1회 이 프롬프트로 한 달 치 주제를 미리 확보해두세요.

## 6장. 고객 관리와 반복 상담 자동화

고객 문의 중 상당수는 이미 답이 정해진 반복 질문입니다. 이를 자동화하면 응대 품질도 오히려 올라갑니다.

### FAQ 자동 응답 시스템 만들기

1. 최근 3개월간 받은 고객 문의를 모두 모읍니다.
2. AI에게 패턴 분석을 요청합니다.

```
아래는 최근 3개월간 받은 고객 문의 목록이야.

[문의 목록 붙여넣기]

1. 가장 자주 반복되는 질문 유형 top 10을 뽑아줘
2. 각 질문에 대한 표준 답변 초안을 작성해줘
3. 답변에 공통으로 들어가면 좋은 정보(링크, 연락처 등)를 표시해줘
```

3. 정리된 FAQ를 웹사이트, 카카오톡 채널 자동응답, 인스타그램 DM 자동응답 등에 등록합니다.

### 고객 온보딩 자동화

신규 고객이 계약/구매 후 받아야 할 안내(이용 방법, 자료, 담당자 연락처 등)를 매번 새로 쓰는 대신, "온보딩 시퀀스"를 미리 만들어두세요.

```
새로운 고객이 [서비스명]을 시작할 때 받아야 할 온보딩 이메일 시퀀스를
3통으로 만들어줘.

1통: 환영 메시지 + 서비스 이용 방법 안내
2통 (가입 3일 후): 자주 놓치는 팁 + 도움이 필요하면 연락할 방법
3통 (가입 7일 후): 만족도 확인 + 추가 문의 유도

톤: 친근하고 신뢰감 있게. 각 메일은 150~200자 내외로.
```

이 시퀀스는 8장에서 다룰 자동화 도구와 연결하면, 고객이 가입한 순간부터 완전히 자동으로 발송되게 만들 수 있습니다.

---

## 7장. 회계·행정 업무 가볍게 만들기

회계는 완전 자동화보다 **"기록 부담을 줄이는 것"**이 현실적인 목표입니다.

### 지출 정리 자동화

영수증 사진을 찍어 모아두고, 월말에 AI에게 정리를 맡기는 방법입니다. (영수증 텍스트를 직접 입력하거나, OCR 앱으로 추출한 텍스트를 붙여넣습니다.)

```
아래는 이번 달 지출 내역이야 (날짜, 항목, 금액).

[지출 목록 붙여넣기]

1. 항목별로 카테고리를 분류해줘 (사무용품, 마케팅, 교통비, 식비, 기타)
2. 카테고리별 합계를 표로 정리해줘
3. 전월 대비 눈에 띄게 늘어난 항목이 있으면 짚어줘
```

### 세금계산서·인보이스 문구 자동화

반복적으로 보내는 인보이스 안내 메시지, 입금 확인 요청, 미납 안내 메시지도 템플릿화하면 매번 감정 소모 없이 처리할 수 있습니다.

```
고객에게 인보이스 결제 기한이 3일 지났다는 것을 알리는 메시지를 써줘.
너무 딱딱하지 않으면서도 정중하게, 관계가 상하지 않도록 부드럽게 표현해줘.
```

### 주의사항

세금 신고, 부가세 계산 등 법적 책임이 따르는 영역은 AI가 참고용 정리를 도울 수는 있어도 **최종 확인은 세무 전문가 또는 홈택스 등 공식 채널**을 통해야 합니다. AI는 여기서 "정리 보조자"이지 "세무사"가 아닙니다.

## 8장. 노코드 도구로 AI 자동화 연결하기 (Zapier·Make)

지금까지는 "AI에게 붙여넣고 결과를 받는" 수동 자동화였습니다. 이제 한 단계 더 나아가, **사람이 개입하지 않아도 자동으로 흐르는 시스템**을 만들 차례입니다.

### 핵심 개념: 트리거 → 액션

모든 노코드 자동화는 이 구조입니다.

```
[트리거: 특정 사건이 발생하면]  →  [액션: 자동으로 이 일을 한다]

예시)
새 구글폼 응답이 접수되면  →  AI가 문의 유형을 분류하고 슬랙으로 알림
새 이메일이 도착하면       →  AI가 답장 초안을 만들어 임시저장함에 넣음
새 고객이 결제하면          →  온보딩 이메일이 자동 발송됨
```

### 추천 조합 (난이도 낮은 순)

1. **구글폼 + 구글시트 + AI**: 문의 폼 응답이 시트에 쌓이면, AI가 매일 정리·요약해서 이메일로 보내줌
2. **Zapier/Make + Gmail + AI**: 특정 키워드가 포함된 메일이 오면 AI가 답장 초안을 자동 생성
3. **Zapier/Make + 결제 도구 + 이메일**: 결제 완료 시 온보딩 시퀀스(6장에서 만든 것) 자동 발송
4. **캘린더 + AI**: 미팅 종료 30분 후 자동으로 "회의록 요약 요청" 알림 발송

### 시작하는 방법

Zapier나 Make(구 Integromat)는 무료 플랜으로도 월 100~1,000회 정도의 자동화 실행이 가능합니다. 처음에는 **가장 자주 반복되는 업무 하나만** 골라 연결해보세요. 예를 들어 "문의 폼 → 슬랙 알림"처럼 단순한 조합부터 시작하는 것이 실패 확률을 줄이는 방법입니다.

## 9장. 4주 자동화 로드맵 — 오늘부터 실행하기

이론은 여기까지입니다. 아래 로드맵을 그대로 따라가면, 한 달 안에 업무의 상당 부분이 자동화된 시스템으로 바뀝니다.

### 1주차: 진단과 템플릿 기초 만들기
- 2장의 자동화 우선순위 매트릭스 작성
- 가장 점수 높은 업무 1~2개 선정
- 이메일 답변 템플릿 3종 제작 (3장)

### 2주차: 문서와 콘텐츠 자동화
- 제안서/견적서 마스터 프롬프트 완성 (4장)
- 이번 달 콘텐츠 주제 15개 확보 (5장)
- 블로그 글 1편 → 파생 콘텐츠 4종 제작해보기

### 3주차: 고객 응대와 회계 정리
- FAQ 자동 응답 템플릿 완성 (6장)
- 온보딩 시퀀스 초안 작성
- 이번 달 지출 내역 AI로 정리해보기 (7장)

### 4주차: 도구 연결하기
- Zapier 또는 Make 무료 계정 생성
- 가장 단순한 자동화 1개 연결 (예: 문의 폼 → 알림)
- 4주간 절약된 시간을 계산해보고, 다음 자동화 대상 재선정

### 체크리스트

```
[ ] 자동화 우선순위 매트릭스 작성 완료
[ ] 이메일 템플릿 3종 이상 확보
[ ] 제안서/견적서 마스터 프롬프트 완성
[ ] 콘텐츠 파생 워크플로우 1회 이상 실행
[ ] FAQ 자동 응답 템플릿 완성
[ ] 노코드 자동화 1개 이상 연결
[ ] 자동화 전후 소요 시간 비교 기록
```

이 체크리스트를 매달 다시 점검하며, 새로운 반복 업무가 생길 때마다 같은 프로세스를 적용하세요. 자동화는 한 번으로 끝나는 것이 아니라 **지속적으로 다듬는 시스템**입니다.

## 부록. 바로 쓰는 프롬프트 라이브러리 30선

### 이메일·커뮤니케이션 (1~6)
1. 문의 답장 템플릿 생성 (3장 참고)
2. 협업 제안 정중히 거절하는 메일 작성
3. 미팅 일정 조율 메일 작성
4. 고객 컴플레인에 공감하며 대응하는 메일 초안 (검토 후 발송 필수)
5. 뉴스레터 구독 환영 메시지
6. 장기 미응답 고객에게 다시 연락하는 메일

### 문서·기획 (7~14)
7. 제안서 마스터 템플릿 (4장 참고)
8. 회의록 요약 및 액션 아이템 정리
9. 프로젝트 진행 상황 보고서 작성
10. 계약 조건 요약 정리 (법적 검토 별도 필요)
11. 견적서 항목별 설명 문구 작성
12. 포트폴리오 소개 문구 작성
13. 자기소개서/회사소개서 다듬기
14. 프레젠테이션 스크립트 초안 작성

### 콘텐츠·마케팅 (15~22)
15. 블로그 글 초안 생성
16. SNS 게시물 파생 생성 (5장 참고)
17. 콘텐츠 주제 15개 브레인스토밍
18. 상품 상세페이지 문구 작성
19. 광고 카피 3버전 A/B 테스트용 생성
20. 유튜브/숏폼 스크립트 작성
21. 이메일 마케팅 캠페인 시퀀스 작성
22. SEO 키워드 기반 블로그 목차 생성

### 고객 관리 (23~26)
23. FAQ 표준 답변 생성 (6장 참고)
24. 온보딩 이메일 시퀀스 작성
25. 고객 만족도 설문 문항 설계
26. 후기 요청 메시지 작성

### 행정·회계 (27~30)
27. 지출 내역 카테고리 정리 (7장 참고)
28. 인보이스 안내 메시지 작성
29. 미납 안내 메시지 (정중한 톤)
30. 월간 업무 회고 정리 (무엇을 자동화했고, 얼마나 시간을 아꼈는지)
