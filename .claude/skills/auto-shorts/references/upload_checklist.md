# 플랫폼 업로드 체크리스트 (폰에서 5분)

Slack DM 으로 `final.mp4` 와 `caption.txt` 가 오면:

## 공통
- 제목·캡션은 `caption.txt` 그대로. 첫 줄이 훅.
- 커버는 자동 생성된 `cover.png`(훅 카드) 또는 영상 첫 프레임.
- 업로드 시간: 평일 18~21시, 주말 10~12시 / 20~22시 사이가 무난. 매일 **같은 시간**.
- 올린 뒤 1시간 안에 달린 댓글엔 직접 답한다(알고리즘·수익화 심사 모두에 유리).

## TikTok
- 1분 이상인지 확인(리워드 대상). 캡션에 해시태그 4~6개.
- 설정에서 "AI 생성 콘텐츠" 표시가 요구되면 켠다(TTS·생성 이미지 사용 시 정책상 표시 권장).
- 크리에이터 리워드: 팔로워 1만 + 30일 10만 조회 도달 시 앱 → 크리에이터 툴에서 신청.

## Naver Clip
- 네이버 앱 → 클립 → 업로드. 관심사 태그 3~5개 + 이달의 미션 해시태그가 있으면 추가.
- 클립 크리에이터 상시 모집: 크리에이터 센터에서 신청(선발 시 보상·미션 참여 가능).
- 같은 주제의 블로그 글이 있으면 본문 링크에 연결(블로그 유입 동시 확보).

## Instagram Reels
- 캡션 첫 줄 훅, 해시태그 5~8개. 커버 프레임 선택.
- 프로필 링크(리틀리 등)에 제휴·전자책 링크 정리.

## YouTube Shorts (자동 업로드된 경우)
- Slack 링크 열어 공개 상태 확인. API 프로젝트 감사 전이면 **비공개 → 공개** 전환.
- 제목 100자 이내, 설명에 #Shorts 자동 포함됨.

## 매주 10분 점검
- 플랫폼별 조회수·평균 시청유지율·팔로워 증가를 표로 기록.
- 상위 20% 주제만 남기고 그 계열로 큐를 채운다("쇼츠 대본 10편 더 만들어서 큐에 넣어줘").
