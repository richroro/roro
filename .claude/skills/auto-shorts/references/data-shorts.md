# 숫자가 주인공인 쇼츠 (공모주·실적·순위)

공모주 분석, 실적 발표, 가격 비교처럼 **시청자가 보고 싶은 게 숫자 그 자체**인 주제가 있다.
여기에 스톡 사진(넥타이 맨 남자가 차트를 가리키는 사진)을 깔면 아무 정보도 전달되지 않는다.
이런 영상은 씬 이미지를 `scripts/datacard.py` 로 직접 그린다 — 네트워크도, 저작권 표기도 필요 없다.

## 쓰는 법

씬에 `card` 를 넣으면 이미지 제공자 체인을 건너뛰고 그 카드를 그린다. `keywords`/`image_prompt` 는 필요 없다.

```json
{ "narration": "기관 경쟁률이 1,109 대 1 나왔습니다.",
  "beats": ["몸값 33% 삭감", "경쟁률 1,109 : 1"],
  "card": { "type": "stat", "label": "기관 수요예측 경쟁률", "value": "1,109 : 1", "note": "2,255건 참여" } }
```

카드 씬은 **모션이 자동으로 `static`** 이 된다(팬/줌으로 밀면 카드가 잘린다). 화면 변화는 `beats` 의
문구 교체와 줌 펀치가 담당한다. `style.card_theme` 으로 `navy`(기본)·`ink`·`teal` 중 고른다.

미리보기: `python scripts/datacard.py --sheet /tmp/cards.jpg`

## 카드 5종

| 종류 | 쓸 곳 | 필드 |
|---|---|---|
| `stat` | 숫자 하나로 때릴 때. 훅 씬에 가장 잘 맞는다 | `label` `value` `note` |
| `compare` | 전 → 후. 가격 인하, 증감 | `left{label,value}` `right{label,value}` `delta` |
| `table` | 결과 정리 3~7줄 | `head` `rows[[라벨,값]]` `highlight`(행 번호) |
| `bars` | 크기 비교. 값이 숫자여야 막대가 그려진다 | `rows[[라벨, 숫자, 표시문구]]` `highlight` |
| `steps` | 일정·단계 | `rows[[라벨,값]]` `done`(완료 개수) |

`source` 를 넣으면 카드 아래에 "출처 …" 가 붙는다. 다만 **여러 씬이 같은 출처면 씬마다 반복하지 말고
`style.disclaimer` 하나로 처리**하는 편이 깔끔하다.

## 면책 문구 (`style.disclaimer`)

투자·의료처럼 시청자가 판단을 내리는 주제에서는 영상 내내 하단에 작게 띄운다.

```json
"style": { "disclaimer": "투자 판단과 책임은 본인에게 있습니다 · 출처 증권신고서(2026-09-19 기준)" }
```

크기·위치는 `disclaimer_size`(기본 40) / `disclaimer_margin_v`(기본 96)로 조정한다.

## 공시 캡처에 빨간 박스 (`capture`)

직접 그린 인포그래픽보다 **원문 표에 빨간 박스 하나** 친 쪽이 훨씬 믿긴다. 씬에 `capture` 를 넣는다.

```json
{ "narration": "확약을 건 물량은 18.14%뿐입니다.",
  "headline": "의무보유확약",
  "capture": {
    "src": "capture/수요예측.png",
    "marks": [ {"type": "spotlight", "row": [2, 5]},
               {"type": "box", "row": [2, 5], "label": "합쳐서 18.14%"} ] } }
```

### 자리 찍는 법 세 가지

| | 뜻 | 언제 |
|---|---|---|
| `"at": [x0,y0,x1,y1]` | 원본 기준 0~1 비율 | 표가 아니거나 정밀하게 찍을 때 |
| `"row": 3` / `[2,5]` | 표 가로 괘선을 검출해 n번째 행 | 표 캡처면 이게 제일 편하다 |
| `"col": 2` | 세로 괘선 기준 n번째 열 | `row` 와 같이 쓰면 칸 하나 |

행·열 번호는 눈으로 세지 말고 뽑아서 본다. 잘못 세면 **엉뚱한 숫자에 박스가 간다**.

```bash
python scripts/annotate.py --src 캡처.png --detect /tmp/d.jpg   # 행·열에 번호를 그려 준다
python scripts/annotate.py --src 캡처.png --grid   /tmp/g.jpg   # at 좌표용 0.1 단위 격자
```

### 표시 종류

`box`(빨간 테두리, 둘레를 따라 그려진다) · `spotlight`(지정한 곳만 남기고 어둡게) ·
`highlight`(형광펜처럼 왼쪽→오른쪽) · `underline` · `strike` · `arrow`.
`label` 을 주면 말풍선이 붙는데 **캡처 바깥 위쪽에** 뜬다 — 숫자를 가리면 캡처를 쓰는 의미가 없다.
표시는 지정한 순서대로 하나씩 등장한다(`style.capture_anim_seconds`, 기본 1.6초).

### 원문 캡처가 없을 때 (`table`)

`src` 대신 `table` 스펙을 주면 공시 수치를 문서 스타일 표로 조판한다. 괘선이 또렷해 `row`/`col`
검출이 그대로 동작한다. **이건 원문 캡처가 아니다** — `note` 에 재구성이라는 사실과 출처를
적어 이미지에 함께 박는다. 캡처인 척하지 않는다.

```json
"capture": { "table": { "title": "기관투자자 수요예측 신청 내역", "unit": "(단위: 건, 주)",
    "head": ["구분","건수","신청수량","비율"], "widths": [1.3,0.8,2.0,0.9],
    "width": 1120, "row_h": 86, "font_scale": 1.45,
    "rows": [["미확약","1,873","946,952,000","81.86%"]],
    "note": "※ 증권신고서 수요예측 결과를 표로 재구성 (원문 캡처 아님)" },
  "marks": [{"type":"box","row":1}] }
```

9:16 화면이라 표는 **세로로 길수록** 글씨가 커진다. `width` 를 1120 근처로 좁히고 `font_scale`
을 1.4~1.5 로 올린다. 칸을 넘치는 글자는 자동으로 줄어든다.

## 목소리 없이 자막만 (`"voice": "none"`)

공시·데이터물은 **듣는 영상이 아니라 읽는 영상**이다. TTS 를 끄면 이런 것이 바뀐다.

- 씬 길이가 자막 길이로 정해진다(읽는 속도 기준)
- 자막이 **문장 통째로** 뜬다. 단어 단위 카라오케는 "경쟁률은 1,109 대 / 1." 처럼 끊겨 읽기가 무너진다
- 줄바꿈은 자막 크기에 맞춰 자동 계산하고, `1,109 대 1` 같은 숫자 표현은 찢지 않는다
- 숫자와 단위가 강조색으로 나온다 — 목소리가 없으면 이게 거의 유일한 시선 유도 장치다
- BGM·효과음은 그대로 남으므로 `bgm.volume` 을 0.45~0.55 로 올린다

자막이 곧 내용이므로 한 씬 한 문장, 25자 이내로 끊는다.

## 공모주 영상에서 지킬 것

1. **수치는 반드시 원문에서 확인한다.** 증권신고서·정정신고서, 거래소 공시. 블로그·요약 기사만 보고
   숫자를 옮기지 않는다. 자릿수 하나가 시청자의 돈이 걸린 판단을 바꾼다.
2. **날짜를 박는다.** 공모 일정은 며칠 만에 바뀐다. 면책 문구에 기준일을 넣어 두면 나중에 본 사람이
   오해하지 않는다.
3. **매수·매도를 권하지 않는다.** "따상 갑니다", "무조건 넣으세요" 같은 표현은 쓰지 않는다.
   사실을 늘어놓고 판단은 열어 둔다 — 마지막 질문형 루프백이 이 역할을 한다.
4. **수익률을 약속하지 않는다.** 과거 사례를 들더라도 "이번에도"로 이어 붙이지 않는다.
5. 회사에 불리한 사실(밴드 인하, 정정 요구, 철회 이력)을 빼지 않는다. 그게 사실은 가장 좋은 훅이다.

## 예시

`examples/ipo-capture.json` — 공시 표 캡처 + 빨간 박스, 나레이션 없이 자막만, 23.6초 5씬.
`examples/ipo-datacard.json` — 같은 소재를 카드로 만든 것.

`shorts_output/ipo-bigwave/project.json` — 빅웨이브로보틱스 공모가 인하 건.
훅은 모순("몸값 33% 깎였는데 경쟁률 1,109 대 1"), 씬 5개에 카드 5종을 한 번씩 쓰고,
마지막은 질문으로 첫 문장에 되돌린다(`loop_back`). 28.9초.

## 소재 찾기

주기적으로 반복되는 주제라 일정만 챙기면 소재가 끊기지 않는다.

- 수요예측 결과 발표일 → `stat`(경쟁률) + `table`(확정가·확약)
- 청약 마감일 → `stat`(경쟁률) + `bars`(증권사별 배정)
- 상장 당일 → `compare`(공모가 → 시초가)
- 밴드 인하·상장 철회 → `bars`(밴드 변화) ← 모순 훅이 가장 강하게 걸린다
