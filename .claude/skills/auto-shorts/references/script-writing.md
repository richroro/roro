# 쇼츠 대본 작법 — 재미있는 주제, 멈추게 하는 훅, 리듬 있는 씬

이 문서는 `project.json` 의 `title / scenes[].narration / headline / image_prompt` 를 쓸 때 읽는다.

## 1. 재미있는 주제 카테고리 (구체 후보 예시 포함)

"재미"의 정체는 대개 **예상 밖(반전) + 내 일상과 연결 + 15초 안에 이해됨** 이다. 아래 카테고리에서
이 세 가지가 다 되는 소재를 고른다. 각 줄의 예시는 그대로 써도 되고 변형해도 된다.

| 카테고리 | 후보 예시 (제목 = 훅) |
|---|---|
| 동물의 황당한 사실 | 문어는 심장이 3개 / 나무늘보는 일주일에 한 번 화장실 / 코끼리는 점프를 못 한다 / 홍학이 분홍색인 이유 / 개미는 잠을 잘까 |
| 인체의 이상한 진실 | 위산은 면도날을 녹인다 / 코가 냄새 1조 개 구분 / 하루에 눈 깜빡임 2만 번 / 재채기 속도 시속 160km |
| 우주·과학 잡학 | 금성은 하루가 1년보다 길다 / 우주에서 울면 눈물이 안 떨어진다 / 번개는 태양 표면보다 뜨겁다 |
| 음식의 비밀 | 꿀은 3천 년 지나도 안 썩는다 / 바나나는 사실 베리, 딸기는 아니다 / 매운맛은 맛이 아니라 통증 |
| 역사 뒷이야기 | 클레오파트라는 피라미드보다 아이폰에 더 가깝다 / 옥스퍼드 대학이 아즈텍 제국보다 오래됐다 / 나폴레옹은 토끼에게 진 적이 있다 |
| 심리학 트릭 | 왜 우리는 밤에 더 감성적일까 / 첫인상은 0.1초 / 선택지가 많으면 오히려 못 고른다 |
| 언어·어원 | '어이없다'의 어이는 맷돌 손잡이? / OK 의 유래 / 왜 알파벳은 그 순서일까 |
| 돈·경제 상식 | 지폐 한 장 만드는 데 드는 돈 / 복권 1등보다 확률 높은 것들 / 왜 가격은 9,900원일까 |
| 일상 속 과학 | 전자레인지 속 포도는 왜 폭발할까 / 샤워할 때 왜 아이디어가 떠오를까 / 빗속을 뛰면 덜 젖을까 |
| 랭킹·비교 | 세계에서 가장 비싼 향신료 TOP3 / 가장 오래 사는 동물 3 / 가장 짧은 전쟁 |
| "만약에" 상상 | 지구가 1초 멈추면 / 인류가 갑자기 사라지면 도시는 / 잠을 안 자면 며칠 버틸까 |
| 기술·인터넷 | 첫 번째 이메일 내용 / 와이파이의 원래 이름 / 왜 로딩바는 거짓말을 할까 |

**피할 소재**: 근거가 흔들리는 건강 정보(특히 '이 습관이 ~를 망친다'식 공포 프레이밍), 특정인 비하, 정치·종교 논쟁, 확인 안 되는 수치 자랑.
**호칭**: '당신'은 쓰지 않는다(공격적으로 들림). '여러분' 또는 주어 없는 문장으로.

## 2. 훅 공식 (첫 씬 첫 문장 + 제목 + 헤드라인이 같은 궁금증을 가리켜야 한다)

| 공식 | 예 |
|---|---|
| 질문형 | "문어 심장이 몇 개인지 아세요?" |
| 반전형 | "꿀은 썩지 않습니다. 3천 년 된 꿀도요." |
| 숫자형 | "여러분은 오늘 눈을 2만 번 깜빡였습니다." |
| 금지형 | "전자레인지에 포도 넣지 마세요. 진짜로요." |
| 비교형 | "클레오파트라는 피라미드보다 아이폰에 더 가까운 사람입니다." |
| 도전형 | "이거 3초 안에 맞히면 상위 1%입니다." |

**기준선: 3초 유지율 70%.** 60% 를 넘긴 영상이 그렇지 않은 영상보다 노출이 3배까지 차이 났다는 테스트가 있다.
훅이 약속한 것은 영상이 끝나기 전에 반드시 지킨다 — 낚시는 다음 영상의 유지율까지 깎는다.

훅 씬의 `beats` 첫 장은 훅의 핵심 숫자/단어만 크게: "심장이 3개?!", "3천 년 꿀", "시속 160km".

## 3. 씬 구조 템플릿 — 2026 리텐션 기준

숫자 세 개만 기억하면 된다.

| 사실 | 그래서 |
|---|---|
| 15~30초 완주율 80%+, 30~60초 50~65%, 60초+ 30~45% | **총 길이 20~30초.** 길게 만들 이유가 없다 |
| 시청자는 **1.5~2초마다** "계속 볼까"를 다시 판단한다 | 그 주기로 화면이 바뀌어야 한다 (`beats`) |
| 3초 유지율 70% 미만이면 훅 실패 — 뒤가 아무리 좋아도 소용없다 | 첫 문장에 배경 설명 금지 |

### 기본형 (20~28초, 씬 6개)

```
씬1  0~4초    훅 = 결론부터    대담한 주장 한 줄. 배경·예고 금지      beats 2, sfx riser
씬2  4~7초    즉답 + 미끼      주장을 인정하고 곧바로 다음 고리를 연다
씬3  7~11초   근거 1           고리 하나 닫고
씬4  11~14초  근거 2           또 하나 닫고
씬5  14~18초  ★반전            가장 센 사실은 여기. 앞에 쓰지 않는다   sfx boom
씬6  18~22초  루프백           첫 문장으로 되돌리는 한 줄            loop_back: true
```

**씬2를 배경 설명에 쓰면 죽는다.** 긴 영상의 "자, 먼저 배경부터"는 쇼츠에선 그대로 이탈 구간이다.
훅 다음은 곧바로 증거다.

**가장 센 사실은 맨 뒤로.** 절정 뒤에 실용 팁이나 덤을 붙이면 거기서 나간다.
(구버전 꿀 영상은 '천연 소독약'을 5번 씬에 놓고 뒤에 팁 2개를 더 붙여 36초가 됐다 → 20.9초로 줄이면서
반전을 끝으로 옮긴 것이 `shorts_output/honey-v2` 다.)

### 열린 고리(open loop)

답을 주기 **전에** 다음 질문을 먼저 연다. "아직 안 끝났다"고 느끼는 동안은 나가지 않는다.

- 좋음 — "꿀은 안 썩습니다. **이유가 좀 무섭고요.**" → 답을 줬는데 새 질문이 열렸다
- 나쁨 — "꿀은 안 썩습니다. 수분이 적어서요." → 여기서 끝. 나갈 이유가 생겼다

### `beats` — 1.5~2초마다 화면 바꾸기

씬마다 이미지를 새로 받으면 20초에 이미지가 12장 필요하다. 대신 씬 **안에서** 문구를 바꾸고 줌 펀치를 준다.
씬당 `beats` 2개면 화면이 약 1.8초마다 바뀐다(`style.beat_seconds`, 기본 1.8).

```json
{ "narration": "꿀은 안 썩습니다. 이유가 좀 무섭고요.",
  "beats": ["꿀은 안 썩는다", "이유가 무섭다"] }
```

- `beats` 가 있으면 `headline` 대신 그 목록이 순서대로 뜬다. 문장 하나에 카드 하나 꼴, 12자 이내.
- 카드는 나레이션을 옮겨 적는 게 아니다. **소리를 끄고 카드만 읽어도 이야기가 되게** 쓴다.
  예: 3000년 된 꿀 → 그대로 먹었다 → 꿀은 안 썩는다 → 이유가 무섭다 → 물이 거의 없다 →
  세균은 말라 죽는다 → 산성도 강하다 → 벌이 넣은 효소 → = 천연 소독약 → 그래서 3000년 → 집에 있는 꿀은?
- 시청자 6할 이상이 소리를 끄고 본다. **거의 모든 씬에 카드가 있어야 한다**(검증기가 80% 미만이면 경고).

### 루프 닫기 (`loop_back`)

마지막 씬에 `"loop_back": true` 를 주면 **첫 씬 그림으로 되돌아가** 영상이 다시 시작될 때 이어져 보인다.
반복 재생은 그대로 시청 시간이라 배급에 유리하다.

- 마지막 나레이션이 첫 문장으로 이어지게 쓴다:
  "그래서 3천 년을 버텼습니다. **집에 있는 꿀은요?**" → 다시 "파라오 무덤에서 꺼낸 꿀…"
- **끝 문장을 먼저 쓰고, 거기에 이어지는 첫 문장을 쓰는 순서**가 제일 쉽다.
- loop_back 씬에서는 `cta` 가 자동으로 빠진다. 마지막 문구가 다음 재생의 훅이라 자리를 내줄 수 없고,
  구독 요청보다 반복 재생이 노출에 더 크게 기여한다.

### 명언 변형 (`style.layout: "quote"`)

사진을 어둡게 깔고 문장을 화면 중앙에 크게. 씬마다 `quote`(` / ` 로 줄바꿈)와 `author`,
`narration` 은 같은 문장을 천천히 읽는다. `dim` 0.35~0.4, `rate` `+0%`, 전환 0.6초, BGM `calm`,
씬당 5초 이상. 이 포맷은 호흡이 생명이라 20~30초 규칙에서 예외로, 씬 5~6개 30초까지 간다.
그림이 어울리면 `style.image_source: "draw"` + 씬별 `art`/`art_palette`, 이때 `dim` 은 0.15로 낮춘다.
출처가 분명한 문장만 쓴다 — 널리 퍼졌지만 귀속이 불확실한 인용은 피하고, 저작권이 지난 고전
(니체·세네카·노자·아우렐리우스 등)이나 출처를 확인할 수 있는 문장을 고른다.

### 랭킹(TOP N) 변형

20~30초면 TOP 5(항목당 4초), 1위는 맨 마지막에. 순위 자체가 열린 고리라 미끼 문장이 따로 필요 없다.

```
씬1  "가장 오래 사는 동물, 5위부터."   beats ["TOP 5", "1위는 마지막"], sfx riser
씬2~5  5위→2위: 씬당 하나. beats ["4위 코끼리거북", "190년"] 처럼 순위 + 숫자
씬6  1위 공개(sfx boom) + 루프백 한 줄, loop_back: true
```

`hook_type` 은 `ranking`, `category` 도 `ranking` 으로 적어 성과를 따로 본다.

- 정보는 **구체적 이미지가 그려지는 것**으로 고른다("피가 파랗다"는 O, "생리학적으로 특이하다"는 X).
- 마지막 문장은 짧게.

## 4. 문장 리듬 (TTS 가 읽었을 때 자연스럽게)

- 한 문장 45자 이내. 긴 문장은 쉼표 대신 마침표로 끊는다 — 자막 덩어리도 깔끔해진다.
- 종결어미 섞기: ~입니다 / ~해요 / ~죠 / ~거든요. 같은 어미 3연속 금지.
- 고유어 수사(개·명·마리·시간·번)는 읽히는 대로: "3개" 보다 "세 개", "2시간" 보다 "두 시간". 한자어로 읽는 큰 수
  (243일, 465도, 900미터, 1,000년)는 숫자 그대로 써도 TTS 가 바르게 읽고 자막도 깔끔하다. 헤드라인은 숫자 기호 OK.
- 영어 단어는 한글로 적는다("Wi-Fi" → "와이파이"). 약어는 풀어 쓴다.
- 말 속도: 정보성·유머 `+8%~+12%`, 미스터리·감성 `+0%`, 아이 대상 `-5%`.
- 글자 수 감각: 공백 포함 **7자 ≈ 1초**(rate +10% 실측, 렌더된 영상 5편 기준. 이전 문서의 5.2자는 틀렸다).
  목표 20~30초 = **140~210자**. 240자를 넘으면 검증기가 경고한다.

## 5. 이미지 프롬프트 요령 (`image_prompt`, 영어)

구조: `[피사체] [행동/상태], [구도], [배경], [조명/분위기]` + 전역 `style.image_style` 이 자동으로 붙는다.

- 좋은 예: `a giant pacific octopus hovering in deep blue water, close-up on its eye, volumetric light rays`
- 나쁜 예: `octopus` (밋밋), `an infographic explaining octopus hearts with labels` (글자 생성 → 오타 덩어리)
- 씬마다 구도를 바꾼다: 클로즈업 → 와이드 → 디테일 매크로 → 인물/동물 반응 컷.
- 추상 개념(확률·시간·돈)은 은유 이미지로: "돈 → 쌓인 동전 위의 작은 사람 미니어처", "시간 → 녹아내리는 모래시계".
- `style.image_style` 추천:
  - 다큐/사실: `cinematic photo, dramatic lighting, high detail, vertical 9:16, no text`
  - 밝은 잡학: `vibrant 3d render, soft studio lighting, pixar style, vertical, no text`
  - 역사: `oil painting style, warm candlelight, museum quality, vertical, no text`
  - 심리/개념: `minimal flat vector illustration, bold colors, simple shapes, vertical, no text`
- `keywords` 는 무료 스톡 사진 검색어다(기본이 사진 우선). **사진이 실제로 존재하는 흔한 영어 명사 2~3개**로 적는다:
  `octopus underwater`, `honey jar`, `bee flower`, `ancient pottery`. 개념어(`three hearts`, `enzyme`)는 사진이 없으니
  은유가 되는 사물로 바꾼다. 여기서 실패한 씬만 `image_prompt` 로 AI 생성된다.
- 하지 말 것: 실존 인물 이름·얼굴, 브랜드/로고, 저작권 캐릭터, 텍스트 생성 요청, 폭력·선정성.

## 6. 헤드라인·효과음·BGM 배치

- 화면 문구는 **거의 모든 씬에** 넣는다(`beats` 2개 또는 `headline` 1개). 12자 이내, 숫자 위주.
  소리 없이 보는 시청자에게는 이 카드가 대본 전체다. "강조 효과가 죽는다"는 걱정은 헤드라인이
  씬당 하나였을 때 얘기고, 지금은 카드가 바뀌는 것 자체가 화면 전환 역할을 한다.
- `sfx`: `riser`(훅 시작, 기대감) / `boom`(반전·충격) / `pop`(가벼운 강조) / `ding`(정답·정리) / `whoosh`(전환).
  한 영상에 2~4개. 전 씬에 넣으면 소음이다.
- `bgm.mood`: 잡학·동물 `playful`, 우주·미스터리 `mysterious`, 감성·심리 `calm` 또는 `lofi`, 역사·스케일 `epic`.
  `bgm.query` 는 영어 3~4단어(`playful curious ukulele`, `dark ambient mystery`).
- `cta` 예: "더 신기한 사실은 구독", "다음 편도 볼래요?", "친구한테 공유해 보세요".

## 7. 흔한 실수

- 훅이 "오늘은 문어에 대해 알아볼게요" 같은 예고편 문장 → 스크롤 넘어감. 바로 사실로 시작.
- **두 번째 씬을 배경 설명에 쓰기** → 가장 흔하고 가장 치명적. 훅 다음은 증거다.
- **가장 센 사실 뒤에 팁·부연을 더 붙이기** → 절정에서 끝내야 한다. 뒤는 잘라낸다.
- 45초·60초를 채우려고 늘이기 → 완주율이 반으로 떨어진다. 20~30초에서 끝낸다.
- 씬 10개 넘게 잘게 쪼개기 → 이미지 수집만 오래 걸린다. 씬 6개 + 씬당 `beats` 2개가 같은 효과를 낸다.
- 나레이션에 "구독과 좋아요 부탁드려요" 5초 → 이탈 구간. `cta` 오버레이로 대체(루프백 영상은 아예 생략).
- 문구 없는 씬 → 소리 끄고 보는 6할에게는 빈 화면이나 마찬가지.
- 이모지·특수기호를 자막에 넣기 → 폰트에 없어 네모로 깨짐.
