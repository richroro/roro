# 숏폼으로 월 500만원 — 2026년 9월 기준 현실 점검과 로드맵

> 조사일 2026-09-18. 플랫폼 정책은 자주 바뀌므로 신청 직전에 공식 페이지에서 재확인할 것.
> 아래 숫자는 공개 기사·가이드에서 인용한 것이며 개인 결과를 보장하지 않는다.

### 자동 업로드 가능 여부 (파이프라인 설계 근거)
- **YouTube Data API**: 업로드 가능. 단 2020-07-28 이후 만든 API 프로젝트는 **감사(audit) 통과 전까지 업로드 영상이 비공개로 강제**. 감사는 구글 클라우드 콘솔 → YouTube API Services → Compliance Audit 신청(무료, 수 주).
- **TikTok Content Posting API**: Direct Post 지원. 하지만 **감사 전엔 비공개 전용 + 24시간 5명 제한**. 개인 채널 하나면 폰 업로드가 빠르다.
- **Naver Clip**: 공개 업로드 API 없음 → 폰 업로드.

## 2. 왜 "조회수 광고 수익"만으론 500만원이 안 되는가

- 유튜브 쇼츠 RPM 50~90원 기준, 500만원 = **월 5,500만~1억 조회**. 신규 채널이 6개월 안에 도달할 숫자가 아니다.
- 틱톡은 한국어 2배 정책으로 유리하지만 역시 팔로워 1만 + 월 10만 조회를 **먼저** 넘겨야 한 푼이라도 나온다.
- 그래서 숏폼은 **유입 엔진**, 돈은 그 뒤에 붙는 4개 층에서 나온다.

## 3. 500만원의 구성 (현실적인 목표 배분)

| 층 | 수단 | 이 저장소의 도구 | 6개월 목표 |
|---|---|---|---|
| ① 플랫폼 보상 | 틱톡 리워드 · 클립 인센티브 · 유튜브 광고 | `auto-shorts`(매일 1편 × 4플랫폼) | 50~150만원 |
| ② 제휴/커머스 | 쿠팡파트너스(링크 클릭 후 구매 전체 수수료), 금융 CPA 제휴 플랫폼(카드·증권 계좌 개설 건당 보상), 네이버 클립 상품태그 | 대본 CTA + 프로필 링크 + 블로그 글(`blogger-auto-post`) | 100~200만원 |
| ③ 디지털 상품 | 전자책·템플릿(통장 쪼개기 시트, 30일 챌린지 표) 1~3만원 | `make-ebook` + 랜딩페이지 | 100~150만원 |
| ④ 서비스 | "1인 사장님 업무 자동화 세팅" 대행 50~150만원/건 | `sales-outreach`(리드 발굴·메일) | 100~200만원 (월 1~2건) |

①은 규모의 게임, ②③④는 **팔로워 5천~1만에서도** 가능하다. 500만원은 ①이 아니라 ②③④가 만든다.

## 4. 90일 실행 계획

**0~30일: 공장 가동**
- 큐에 대본 30편(Claude 가 하루치 5~10분에 작성). `shorts-daily.yml` 이 매일 18:00 렌더.
- 4개 플랫폼 계정 세팅(같은 이름·프로필·링크). Naver Clip 크리에이터 신청(상시).
- 매일: Slack 으로 온 mp4 를 틱톡·클립·릴스에 올리기(5분). 유튜브는 자동(감사 전엔 공개 전환 10초).
- 지표: 편수 30, 팔로워보다 **평균 시청유지율**을 본다. 3초 이탈 훅부터 고친다.

**31~60일: 포맷 확정 + 제휴 붙이기**
- `data/posted_log.json` + 플랫폼 분석으로 상위 20% 주제만 남기고 그 계열로 큐 채움.
- 쿠팡파트너스·금융 CPA 플랫폼 가입, 프로필 링크(리틀리 등)에 정리. 대본 CTA 를 "프로필 링크" 로.
- 블로그 글 ↔ 쇼츠 주제 동기화(같은 주제를 글+영상으로).
- 지표: 팔로워 합산 3천, 링크 클릭 수 측정 시작.

**61~90일: 상품 + 서비스**
- 가장 반응 좋은 주제로 전자책 1권(`make-ebook`) → 쇼츠 CTA 로 판매.
- `sales-outreach` 로 1인 사업자 20곳에 "이 자동화 그대로 세팅해드림" 제안.
- 틱톡 1만 팔로워·클립 인센티브 조건 진입 시도. 미달이어도 ②③④는 굴러간다.

## 5. 현실적인 기대치와 리스크
- 대부분의 정보형 페이스리스 채널은 **첫 100편**까지 조회수가 미미하다. 이 저장소의 블로그도 한 달간 총 조회 17회였다(`blogger-auto-post/data/stats_history.json`). 숏폼은 노출 알고리즘이 있어 블로그보다 초반 유입이 빠르지만, 여전히 "편수 × 시간"이 필요하다.
- 플랫폼은 **AI 생성·반복 템플릿 콘텐츠를 수익화에서 제외**하는 방향으로 움직이고 있다(유튜브 2025-07 "비진정성 콘텐츠" 정책 강화). 대응: 나레이션 대본을 내 경험·의견으로 고치고, 주기적으로 카드 디자인·보이스·구성을 바꾸고, 댓글에 직접 답한다. 완전 무인은 **제작**까지, **소통**은 사람이 한다.
- 금융 콘텐츠는 "특정 상품 추천·수익 보장" 표현을 피한다(광고 표시 의무·금소법). 제휴 링크는 반드시 "광고/제휴" 표시.
