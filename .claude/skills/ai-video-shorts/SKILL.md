# AI 영상 쇼츠 제작 (Seedance 2.0 / Higgsfield 오케스트레이션)

Claude는 영상을 **직접 렌더링하지 않는다.** 대신 AI 영상 생성 툴에 그대로 붙여넣을
**제작 패키지**(컨셉·씬별 생성 프롬프트·나레이션 대본·자막·음악 디렉션·발행 메타)를
만들고, 사용자가 툴에서 뽑아온 클립을 `scripts/assemble.py`로 이어붙여 9:16 세로
영상 하나로 완성하는 것까지 안내한다.

- **시댄스 / 시드댄스 2.0** = ByteDance **Seedance 2.0** (텍스트/이미지→영상 생성)
- **핵스필드** = **Higgsfield** (AI 영상 생성 · 카메라 무빙 프리셋 특화)

두 툴 다 웹/구독형 서비스라 공식 무료 API가 없으므로, 이 스킬은 **프롬프트를 만들고
사람이 생성한 결과를 조립**하는 방식으로 자동화한다.

## 언제 이 스킬을 쓰는가
- "AI로 쇼츠/숏폼/릴스 만들어줘", "영상 자동으로 만들어줘"
- "시드댄스(Seedance)/핵스필드(Higgsfield)로 영상 프롬프트 짜줘"
- 특정 주제로 세로 영상 한 편의 기획·프롬프트·대본·자막·해시태그가 필요할 때
- 이미 생성한 클립들을 하나로 이어붙이고 자막/배경음을 얹고 싶을 때

## 0단계. 범위 확정 (생략하지 말 것)

주제만 던져진 경우 곧바로 쓰지 말고 **AskUserQuestion으로 아래를 먼저 확인**한다.
사용자가 이미 답을 준 항목은 다시 묻지 않는다.

1. **주제·목표** — 무엇에 관한 영상이고 왜 만드는가 (예: 업무 자동화 홍보 / 정보전달 / 브랜딩)
2. **길이·씬 수** — 15초(3~4씬) / 30초(5~7씬) / 45~60초(8~12씬)
3. **어떤 생성 툴** — Seedance 2.0 / Higgsfield / 둘 다 (프롬프트 형식을 툴에 맞춰 조정)
4. **비주얼 톤** — 실사(cinematic) / 애니·일러스트 / 모션그래픽·텍스트 위주 / 믹스
5. **나레이션 유무** — 보이스오버 대본을 넣을지, 자막(무음)만 갈지

답이 없거나 애매하면 기본값: **30초 · 실사 시네마틱 · Seedance+Higgsfield 둘 다 ·
한국어 나레이션 + 자막**. 사용자의 목표(메모리상 업무 자동화 사업)와 맞으면 그
방향으로 훅과 CTA를 잡는다.

## 1단계. 파일 위치

프로젝트 루트에 `<주제-slug>-shorts/` 폴더를 만들고 그 안에 저장한다.

```
<slug>-shorts/
  plan.md            # 제작 패키지 (필수, Claude가 작성)
  captions.srt       # 자막 파일 (자막 번인/업로드용)
  clips/             # 사용자가 생성한 클립을 넣는 폴더 (01_*.mp4, 02_*.mp4 ...)
  bgm.mp3            # (선택) 배경음악
  final.mp4          # assemble.py 결과물
```

## 2단계. 제작 패키지 작성 (`plan.md`)

Write 도구로 직접 작성한다. 아래 구조를 뼈대로 삼되 주제에 맞게 새로 구성한다 —
템플릿을 그대로 복사하지 말 것.

1. **컨셉 & 후킹** — 한 줄 컨셉 + **첫 3초 훅**(스크롤을 멈추게 할 오프닝). 훅은
   시각(무엇이 보이나) + 텍스트(화면 문구) 둘 다 적는다.
2. **전체 구성 표** — 씬 번호 / 길이(초) / 화면 내용 / 자막 / 나레이션 요약을 표로.
   길이의 합이 0단계에서 정한 총 길이와 맞아야 한다.
3. **씬별 생성 프롬프트** — 각 씬마다:
   - **영문 생성 프롬프트** (Seedance/Higgsfield는 영문 프롬프트가 안정적). 반드시
     포함: 피사체·행동 / 배경·분위기 / **카메라 무빙**(dolly in, orbit, handheld 등) /
     조명 / 스타일·화질 키워드(cinematic, 9:16 vertical, 4k) / **길이**.
   - **Seedance vs Higgsfield 팁**: Higgsfield는 카메라 무빙 프리셋 이름을 그대로 쓰고,
     Seedance는 이미지→영상이면 시작 프레임 설명을 덧붙이라고 명시.
   - 네거티브/주의 키워드(원치 않는 요소 배제).
4. **나레이션 대본** (나레이션 있을 때) — 씬 순서대로 한국어 구어체, 씬당 1~2문장.
   말 속도 기준 대략 "1초에 한글 5~6자"로 길이를 맞춘다(초과하면 문장을 줄인다).
5. **자막(온스크린 텍스트)** — 씬별 화면 문구. 짧고 큰 글씨용으로 한 줄 12자 내외.
   이 내용은 그대로 `captions.srt`에도 타임코드와 함께 옮긴다.
6. **음악 · 효과음 디렉션** — 장르/BPM/무드, 훅·전환·엔딩에 넣을 SFX 포인트.
7. **발행 메타** — 플랫폼별(YT Shorts / Reels / TikTok):
   - 제목/캡션 (첫 줄에 훅), 해시태그 5~10개, 업로드 팁(세로 1080x1920, 커버 프레임).

**품질 기준**
- 과장·허위 수치나 검증 안 된 통계를 지어내지 않는다("일반적으로/예시" 표기).
- 저작권 있는 음원·타인 얼굴·상표를 프롬프트에 요구하지 않는다. 실존 인물/브랜드
  모사는 넣지 않는다.
- 프롬프트는 실제로 복붙해 바로 생성 가능한 완성형이어야 한다.

## 3단계. 자막 파일 생성 (`captions.srt`)

`plan.md`의 씬별 자막 + 길이를 근거로 타임코드를 누적 계산해 표준 SRT를 Write로
직접 쓴다. 형식:

```
1
00:00:00,000 --> 00:00:04,000
화면 문구 첫 줄

2
00:00:04,000 --> 00:00:09,000
다음 자막
```

## 4단계. 클립 생성 안내 (사용자 작업)

사용자에게 다음을 안내한다:
1. `plan.md`의 씬별 영문 프롬프트를 순서대로 Seedance 2.0 / Higgsfield에 붙여넣어 생성.
2. 각 클립을 **9:16 세로**로 뽑고, `clips/` 폴더에 **`01_`, `02_` …** 순번 접두어로 저장.
   (조립 순서는 파일명 정렬 순서를 따른다.)
3. 다 모이면 알려달라고 한다 — 그다음 조립을 진행.

## 5단계. 조립 (`scripts/assemble.py`, 선택)

클립이 모이면 ffmpeg로 이어붙이고 자막·배경음을 얹는다. **먼저 ffmpeg 설치를
확인**한다(`ffmpeg -version`). 없으면 조립은 건너뛰고 설치 안내만 한다
(Windows: `winget install Gyan.FFmpeg`), 나머지 재료(plan.md·srt)는 그대로 쓸 수 있음을
알린다.

```bash
python .claude/skills/ai-video-shorts/scripts/assemble.py \
  --clips "<slug>-shorts/clips" \
  --output "<slug>-shorts/final.mp4" \
  --subtitles "<slug>-shorts/captions.srt" \
  --bgm "<slug>-shorts/bgm.mp3" \
  --bgm-volume 0.25
```

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--clips` | 클립 폴더(파일명 정렬 순으로 이어붙임) | (필수) |
| `--output` | 결과 mp4 경로 | `final.mp4` |
| `--subtitles` | SRT 자막 파일 (있으면 영상에 번인) | 없음 |
| `--bgm` | 배경음악 파일 | 없음 |
| `--bgm-volume` | 배경음악 볼륨(0~1) | `0.3` |
| `--width`/`--height` | 출력 해상도 | `1080`/`1920` |
| `--fps` | 출력 fps | `30` |

동작: 각 클립을 9:16(1080x1920)로 중앙 크롭·정규화한 뒤 순서대로 concat하고,
자막이 있으면 하드번인, BGM이 있으면 원본 오디오와 믹스한다. 자세한 제약은
스크립트 상단 주석 참고.

## 6단계. 마무리 안내

사용자에게 전달한다:
- `plan.md` 경로 (씬별 프롬프트·대본·자막·해시태그)
- `captions.srt` 경로
- 클립을 `clips/`에 순번대로 넣는 방법
- (ffmpeg 있으면) `final.mp4` 결과 / (없으면) 설치 안내
- 다음 제안(썸네일/커버 문구, 다른 플랫폼용 리사이즈, 후속편) — 먼저 만들지 말고
  필요 여부만 짧게 제안.
