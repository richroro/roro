# 쿠팡 파트너스 시작 & API 키 발급 (한 번만)

쿠팡 파트너스는 내 블로그·SNS에 쿠팡 상품 링크를 걸고, 그 링크로 구매가 일어나면
수수료(카테고리별 대략 1~3%)를 받는 제휴 프로그램입니다. 아래는 가입부터 이 스킬이
API 를 쓸 수 있게 되기까지의 순서입니다. 정책·수수료·승인 기준은 쿠팡이 바꿀 수 있으니
**파트너스 대시보드의 안내가 항상 우선** 입니다.

## 1. 가입
1. https://partners.coupang.com 접속 → 쿠팡 계정으로 로그인 → 파트너스 가입.
2. 개인도 가능합니다(사업자 없어도 됨). 정산을 위해 본인 명의 계좌·신분 확인이 필요합니다.
3. **채널 등록:** 링크를 올릴 곳의 주소를 등록합니다.
   - 블로그: `https://riririririch.blogspot.com/`
   - 스레드·유튜브 등 다른 채널도 있으면 함께 등록 (등록 안 된 채널에 올리면 정책 위반)

## 2. 활동 시작 (API 키 없이도 가능)
가입 직후에는 **임시 승인** 상태입니다. 이 단계에서는 API 는 안 되지만 링크는 만들 수 있습니다.
1. 대시보드 → **링크 생성 → 간편 링크 만들기** 에 쿠팡 상품 URL 붙여넣기 → `https://link.coupang.com/a/...` 생성.
2. 그 링크를 이 스킬의 `render.py --item "링크|상품명|가격|이미지URL"` 로 상품 블록으로 만들어 글에 넣습니다.
3. 글마다 고지 문구가 들어갔는지 확인합니다 (blogger 발행 스크립트가 자동 삽입).

## 3. 최종 승인
- 누적 구매 실적이 **15만 원 이상** 이 되면 쿠팡이 등록 채널을 검수해 **최종 승인** 합니다.
  (검수 항목: 고지 문구 표기, 채널이 실제로 운영되는지, 정책 위반 여부 등)
- 최종 승인 전에는 정산도, API 키 발급도 되지 않습니다. 승인 여부는 대시보드 상단 상태와 이메일로 알려줍니다.

## 4. API 키 발급
1. 최종 승인 후 대시보드 → **링크 생성 → API** 메뉴에서 **API 키 발급** 버튼이 활성화됩니다.
2. **Access Key** 와 **Secret Key** 두 개가 나옵니다. Secret Key 는 발급 시점에만 보이니 바로 저장하세요.
3. 이 저장소에서:
   ```
   .claude/skills/coupang-partners/secrets/.env.example  →  복사해서  .env
   ```
   ```
   COUPANG_ACCESS_KEY=발급받은_액세스키
   COUPANG_SECRET_KEY=발급받은_시크릿키
   COUPANG_SUB_ID=blog
   ```
   `COUPANG_SUB_ID` 는 링크에 붙는 채널 구분값입니다. 리포트에서 채널별 성과를 나눠 보려면
   블로그는 `blog`, 스레드는 `threads` 처럼 채널마다 다르게 씁니다 (영문·숫자만).
4. 점검:
   ```bash
   python .claude/skills/coupang-partners/scripts/setup_check.py
   ```
   "성공! 제휴 링크 예시: ..." 가 나오면 끝입니다.

> `secrets/` 폴더는 `.gitignore` 로 git 에서 제외됩니다. 다른 컴퓨터에서 쓰려면 `.env` 를
> 직접 옮기세요. 키가 유출된 것 같으면 대시보드에서 재발급하면 이전 키는 무효가 됩니다.

### (선택) GitHub Actions 에서 쓰려면
지금 구조에서는 링크 생성이 Claude 와 대화 중에 일어나므로 Actions 에 키가 필요 없습니다.
나중에 무인 생성(`generate.py`)에서 상품을 자동으로 붙이고 싶다면 저장소 Settings → Secrets 에
`COUPANG_ACCESS_KEY` / `COUPANG_SECRET_KEY` 를 넣고 워크플로 `env:` 로 넘기면 됩니다.
`common.py` 는 환경변수가 있으면 `.env` 파일 없이도 동작합니다.

## 5. 꼭 지켜야 하는 규정 (계정 정지 사유)
- **고지 문구:** 링크가 있는 모든 글에 아래 문구를 **눈에 잘 띄는 곳** 에 넣습니다.
  > 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
  이 저장소의 블로거 발행 스크립트는 쿠팡 링크를 감지하면 본문 맨 위에 자동으로 넣습니다.
- **본인 구매 금지:** 내 링크로 내가(가족 포함) 사면 안 됩니다.
- **등록 채널에만 게시:** 미등록 채널·카페·단톡방 도배·스팸성 전송 금지.
- **링크 변형 금지:** 생성된 링크를 임의로 고치거나 다른 단축 서비스로 감싸지 않습니다.
- **허위·과장 금지:** 없는 할인, 써 보지 않은 후기, "최저가 보장" 같은 표현을 쓰지 않습니다.
- **쿠팡 로고·상표:** 쿠팡 로고 이미지를 마음대로 쓰거나 "쿠팡 공식" 처럼 보이게 하지 않습니다.

## 6. 알아두면 좋은 것
- **호출 제한:** 검색 API 는 시간당 약 10회입니다. 이 스킬은 같은 요청을 6시간 캐시합니다.
- **골드박스:** 매일 바뀌는 특가라 글을 묵히면 링크가 죽습니다. 당일 발행용으로만 쓰세요.
- **정산·세금:** 수수료는 월 단위로 정산되며, 개인은 사업소득으로 원천징수(3.3%)됩니다.
  연 소득 규모에 따라 종합소득세 신고 대상이 될 수 있으니 5월에 확인하세요.
- **성과 확인:** 대시보드 리포트 또는 `report.py --days 30` 으로 클릭·주문·수익을 봅니다.
  블로그 글마다 다른 `subId` 를 쓰면 어떤 글이 팔았는지까지 나눠 볼 수 있습니다.
