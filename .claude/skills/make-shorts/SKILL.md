# 쇼츠 영상 만들기 (웹캠 녹화 + 필터)

`scripts/record_shorts.py` 로 웹캠을 열어 9:16 세로 비율 mp4를 녹화한다.
`ascii_webcam.py` / `face_character_filter.py` / `eye_sunglasses_filter.py` 의
필터 로직을 `scripts/filters.py` 로 재사용 가능하게 뽑아 놓았다.

## 언제 이 스킬을 쓰는가

- 사용자가 "쇼츠", "숏폼", "릴스", "세로 영상"처럼 짧은 세로형 영상을 만들어 달라고 할 때
- 웹캠으로 얼굴 필터(캐릭터 얼굴, 선글라스, 아스키아트) 효과를 넣어 녹화하고 싶을 때

## 실행 전 반드시 확인할 것

이 스크립트는 **실제로 카메라를 켜고 GUI 미리보기 창을 띄운다.** 사용자가 카메라 앞에
있을 준비가 된 상태에서만 실행해야 한다. 실행 전에 반드시:

1. 어떤 필터를 쓸지, 몇 초짜리로 찍을지, 자막 문구가 있는지 확인한다.
2. 사용자에게 "지금 카메라를 켜고 N초 녹화를 시작해도 될지" 확인한다.
3. 백그라운드로 자동 실행하지 않는다 (사람이 화면을 보고 카운트다운에 맞춰 준비해야 함).

## 사용법

```bash
python .claude/skills/make-shorts/scripts/record_shorts.py \
  --filter character \
  --duration 15 \
  --caption "오늘의 하이라이트" \
  --countdown 3
```

옵션:

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--filter` | `none` / `character`(캐릭터 얼굴) / `sunglasses`(선글라스) / `ascii`(아스키아트) | `none` |
| `--duration` | 녹화 길이(초), 1~60초로 제한됨 | `15` |
| `--caption` | 상단에 넣을 자막 텍스트 (한 줄) | 없음 |
| `--width` / `--height` | 출력 해상도 (세로형 기본 1080x1920) | `1080` / `1920` |
| `--fps` | 출력 프레임레이트 | 미지정 시 카운트다운 동안 실측한 카메라 fps 사용 (실패 시 24) |
| `--countdown` | 녹화 시작 전 카운트다운(초) | `3` |
| `--output` | 저장 경로 | `shorts_output/shorts_<타임스탬프>.mp4` |

실행 중 카메라 창에서 `q`를 누르면 조기 종료(카운트다운 중이면 취소, 녹화 중이면 그때까지
찍은 분량으로 저장)된다.

## 동작 방식 / 제약

- 원본 웹캠 프레임을 가운데 기준으로 9:16 비율로 크롭한 뒤 지정 해상도로 리사이즈한다.
- OpenCV `VideoWriter`(mp4v 코덱)로 저장하므로 **ffmpeg 설치 없이도 mp4 생성이 된다.**
- **오디오 트랙은 없다 (무음 영상).** 마이크 녹음/배경음악을 넣으려면 별도로 ffmpeg 설치 및
  오디오 합성 단계가 필요하며, 이 스킬 범위 밖이다. 필요하면 사용자에게 ffmpeg 설치 여부를
  먼저 확인하고 안내할 것.
- 얼굴 인식은 OpenCV Haar cascade 기반이라 조명/각도에 따라 인식이 불안정할 수 있다.
- `ascii` 필터는 프레임마다 텍스트를 다수 그리므로 다른 필터보다 느릴 수 있다(체감 프레임 드랍
  가능). 부드러운 결과가 필요하면 `--fps`를 낮추거나 `character`/`sunglasses`를 권장.

## 완료 후

스크립트가 끝나면 저장된 파일 경로와 프레임 수/길이를 출력한다. 결과 파일 위치를 사용자에게
알려주고, 필요하면 다른 필터나 자막으로 다시 찍을지 물어본다.
