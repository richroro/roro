# 네이버 메일 SMTP 발송 설정 (최초 1회)

이 스킬은 사용자 **본인 메일 계정**으로 직접 발송합니다. 별도 서버 없이
네이버(또는 Gmail 등)의 SMTP를 씁니다. 아래는 네이버 기준.

## 1. POP3/SMTP 켜기
1. 네이버 메일 접속 → 우측 상단 **환경설정(톱니)**
2. 좌측 **POP3/SMTP 설정** 탭
3. **POP3/SMTP 사용** 을 **사용함** 으로 저장
   - 여기 안내에 SMTP 서버명(`smtp.naver.com`), 포트(`465`, 보안연결 SSL)가 나옵니다.

## 2. 애플리케이션(앱) 비밀번호 발급
네이버는 외부 프로그램 로그인에 **로그인 비밀번호가 아니라 앱 비밀번호**를 씁니다.
1. 네이버 → 우측 상단 프로필 → **내 정보** → **보안 설정**
2. **2단계 인증** 을 켠 뒤 → **애플리케이션 비밀번호 관리**
3. 새 앱 비밀번호 생성(예: 이름 "메일발송") → 나오는 **16자리 비밀번호 복사**
   - 이 값은 한 번만 보이니 바로 `.env` 에 넣으세요.

> 계정 보안: 앱 비밀번호는 언제든 이 화면에서 **폐기(재발급)** 할 수 있습니다.
> 노출됐다 싶으면 폐기 후 새로 발급하세요.

## 3. .env 채우기
`secrets/.env.example` 를 `secrets/.env` 로 복사하고 값 입력:
```
SMTP_HOST=smtp.naver.com
SMTP_PORT=465
SMTP_USER=from0731@naver.com
SMTP_PASSWORD=<위에서 복사한 16자리 앱 비밀번호>
FROM_NAME=김병채
REPLY_TO=from0731@naver.com
```
> 비밀번호는 사용자가 직접 이 파일에 넣습니다. Claude 는 비밀번호 값을
> 입력·요청하지 않으며, 스크립트는 이 `.env` 에서만 읽습니다.

## 4. 발송 테스트 (자기 자신에게)
```bash
echo "테스트 본문입니다." > /tmp/test.txt
python .claude/skills/sales-outreach/scripts/send_email.py \
  --to from0731@naver.com --subject "발송 테스트" --body-file /tmp/test.txt --send
```
받은편지함에 도착하면 설정 완료입니다.

## 발송량 주의 (계정 보호)
- 네이버 개인 계정은 **하루 발송량 제한**이 있습니다. 이 스킬 기본 상한은
  하루 20건, 발송 간 45초 지연입니다. 상한을 무리하게 올리면 계정이 일시
  제한될 수 있으니 소량·정밀 발송을 권장합니다.
- 대량이 필요해지면 전용 발송 서비스(예: 비즈메일, SendGrid 등) 도입을 고려하세요.
