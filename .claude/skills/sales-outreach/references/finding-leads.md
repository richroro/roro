# 1인기업 리드 찾는 법 (Claude 웹 리서치 가이드)

목표: **혼자 운영하는 사업자** 중, 반복 업무를 자동화하면 실제로 도움이 될
후보를 찾아 공개된 문의 이메일과 함께 `leads.csv` 로 정리한다.

## "1인기업" 신호 (이런 곳을 노린다)
- 대표=운영자 1명인 소규모: 공방/스튜디오/1인 쇼핑몰/프리랜서/1인 컨설턴트
- "혼자 만듭니다", "1인 운영", "대표 직접 응대" 같은 소개 문구
- 예약/문의를 **인스타 DM·카톡·전화 하나로만** 받는 곳 (자동화 여지 큼)
- 리뷰·주문은 많은데 응대는 한 명이 다 하는 티가 나는 곳

## 어디서 찾나 (공개 출처만)
- 네이버 **블로그/플레이스**, **인스타그램** 비즈니스 프로필의 공개 문의 이메일
- **스마트스토어/아이디허스/자사몰**의 "판매자 정보"·"문의" 페이지
- **크몽/숨고/탈잉** 등 프리랜서·전문가 프로필의 공개 연락처
- 업종 디렉터리, 지역 상권 소개, 수공예 마켓(아이디어스 등) 셀러 소개
- 개인 홈페이지의 "Contact" / 하단 footer 이메일

### 검색 팁 (WebSearch)
- `"수제 가죽공방" 문의 이메일 인스타`
- `1인 쇼핑몰 대표 스마트스토어 판매자 이메일`
- `프리랜서 디자이너 포트폴리오 contact @`
- 지역 한정: `부산 1인 카페 예약 인스타`

## 반드시 지킬 것 (수집 원칙)
1. **공개된 비즈니스 문의처만.** 로그인·비공개 영역, 개인 사생활 정보 금지.
2. **개인정보 결합 금지.** 여러 출처를 엮어 프로필을 만들지 않는다.
3. 이메일이 **영업 수신 거부**를 명시("광고 사절" 등)하면 수집하지 않는다.
4. 추정 이메일을 지어내지 않는다. **실제로 페이지에 적힌 주소만** 넣는다.
5. 리드마다 **개인화 훅 1문장(hook)** 을 반드시 메모한다. 훅 없으면 발송 제외.

## 좋은 훅(hook) 쓰는 법
"이 사람의 어떤 반복 업무를, 자동화로 어떻게 덜 수 있는가"를 한 문장으로.
- 나쁨: "자동화가 필요해 보임" (뻔함, 개인화 아님)
- 좋음: "예약을 인스타 DM으로만 받고 계셔서, 자동 예약+전날 리마인드가 잘 맞음"
- 좋음: "신상 공지를 인스타/블로그에 따로 올리셔서, 한 번에 발행 자동화가 유용"

## 정리 (leads.csv 에 넣기)
찾은 후보를 한 건씩:
```bash
python .claude/skills/sales-outreach/scripts/add_lead.py \
  --name "대표/호칭" --email "hi@example.com" --company "상호" \
  --niche "업종" --source "찾은 곳" --hook "개인화 훅 1문장"
```
중복 이메일은 자동으로 건너뛴다. 정리 후 사용자에게 **후보 목록을 요약**해
보여주고, 어디에 어떤 템플릿으로 접촉할지 함께 정한 뒤 발송 단계로 넘어간다.
