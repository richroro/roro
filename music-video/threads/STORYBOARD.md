# 쇼츠 · "스레드어, 몇 개 알아?" (스레드 문화)

세로 1080×1920, **59.8초**. 한국 스레드(Threads)의 문화를 **퀴즈쇼**로 푼다.

앞의 두 쇼츠와 다르게 간다.
- **구조:** 빌리 아일리시 쇼츠는 시간 순서 4막, 리센느 쇼츠는 결말부터 되감기였다. 이번엔 **퀴즈쇼**다.
  단어 → 3·2·1 타이머(박자) → 땡! → 정답 카드를 네 번 반복하고, 보너스 문제로 "왜 반말이야?"를 푼 다음,
  숫자로 크기를 보여 주고 끝난다.
- **캐릭터:** 실존 인물이 아니라 지어낸 **털실 뭉치**들이다. 스레드(thread)는 실이고, 이어지는 글 묶음을 부르는 말
  '타래'도 실타래에서 왔다. 그래서 얼굴(펠트 눈, 수놓은 입)을 마음껏 그린다. 세계는 뜨개질 배경, 펠트 카드,
  바느질 라벨, 캐릭터들을 잇는 털실 가닥.
- **음악:** 〈고딩 라이프〉의 16~48마디를 808·스냅·하이햇의 트랩풍 베드룸 팝(`song/darkpop.mjs`)으로 새로 편곡했다. 보컬 없음.

## 원칙

- **사실만:** 용어 뜻과 숫자는 아래 표 그대로 쓴다. 새 용어, 숫자, 인용을 만들지 않는다.
- **로고 없음:** 스레드(@ 모양) 로고, 앱 아이콘을 그리지 않는다. 휴대폰 화면은 일반적인 피드(털실 아바타, 이름,
  글, 하트·댓글·리포스트 아이콘)로.
- 게시물 속 문장("안녕하십니까" 등)은 장면을 위한 예시다. 실존 계정을 흉내 내지 않는다.

## 도구 (`src/yarn.js`)

- `yarnBall(x, y, r, { t, color, face, arms, tie, glasses, hat, squash, tail, look, seed })`
  - face: happy, grin, shock, wink, cry, smug, think, love, stiff
  - arms: none, wave, up, hips, type, point
  - hat: beanie, bow
- `strand(pts, color, { t, w, wob })` 털실 가닥, `knitBg(t, a, b)`, `feltCard(x, y, w, h, { fill, rot, fn })`
- `quizWord(t, t0, word, { x, y, w, h, size, fill, q })`, `timer(t, t0, x, y, r)` (t0 다음 세 박자에 3·2·1, 넷째 박에 땡!),
  `answer(t, t0, text, { x, y, size, fill })`
- `stitchTag(t, t0, t1, text, { size, y, colors })` 큰 자막, `stitchSub(...)` 손글씨(개구체) 작은 자막
- `bubble(x, y, text, size, { tail, fill })`, `hearts()`, `phoneFeed(x, y, s, fn)`, `post(x, y, w, text, { t, name, face, color, liked })`,
  `bigNum(t, t0, value, suffix, x, y, size, { dur, decimals, color })`, `handText(txt, x, y, size, color, o)`
- core.js 의 `camBegin/camEnd`, `shakeXY`, `kf`, `pulse`, `hop`, `confetti`, `speedLines`, `sunburst`, `flash`.

인물·주요 사물은 가운데(y 700~1650)에, 자막은 위쪽(y 250~750)에 둔다. 아래 300px에는 중요한 것을 두지 않는다.

**퀴즈 한 문제의 박자(7.27초 = 4마디):** q0 에 단어 카드가 쾅 → q0+0.91 부터 `timer` 3·2·1 → q0+2.27 땡! →
q0+2.73 정답 카드 → q0+4.55 덧붙임 자막 → q0+7.27 다음 문제. 답을 기다리는 동안 털실 캐릭터들이 고민(think),
땡! 에 놀람(shock), 정답에 환호(grin, up).

## 출처

- 반말 문화("처음 보는 사람에게도 자연스럽게 반말"), 스친(스레드 친구), 스하리(팔로우·좋아요·공유를 해 주겠다)와
  답례 반하리, 스팔·스린이·쓰하 같은 줄임말, 나이·직급이 흐려지며 가까워진다는 분석: 우먼센스(2026.2), 헤럴드경제.
- 스린이 = 스레드 초보, 쓰하 = 스레드 하이: 스레드 이용자들이 정리한 용어 모음, 임프레스워드.
- 국내 월간 이용자 1년 전 532만 → 2026년 5월 665만, 한국 앱 이용 시간 전년 동기 대비 80% 이상 증가,
  전 세계 월간 이용자 5억 명 돌파: 이데일리, 네이트 뉴스(2026.6.17).
