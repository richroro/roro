# 쇼츠 · "제나의 트로트 메들리" (리센느 제나 이야기)

세로 1080×1920, **59.7초**. 2026년 9월 18일 원이의 유튜브 채널에 올라온 추석 특집 영상 '제나의 트로트 메들리'가
며칠 만에 수백만 회를 찍고, 장윤정까지 화답한 이야기.

앞의 쇼츠들과 다르게 간다.
- **구조:** 영상 전체가 **노래방 반주기 화면**이다. 곡 번호 입력 → 제목 화면 → 전주·1절(가사 자리에 사실 자막이
  노래방 가사처럼 색이 채워짐) → 선곡표(메들리 곡이 한 마디에 한 곡씩 넘어감) → 앙코르(반응) → 박수 화면.
- **캐릭터:** 16비트 **픽셀 스프라이트**. 실존 인물이라 눈은 없다(앞머리가 가린다). 머리·옷 색은 구분용이고
  특정 멤버를 흉내 내지 않는다. 가운데 마이크 든 스프라이트가 제나(막내), 뒤의 넷이 코러스 언니들.
- **음악:** 새로 작곡한 오리지널 **뽕짝 트로트** 반주(`song/trot.mjs`). 메들리 곡들의 멜로디나 가사는 쓰지 않았다.
  곡 제목만 화면에 나온다(가사 없음).

## 원칙

- **사실만:** 화면 글자는 아래 표 그대로. 새 사실, 숫자, 인용을 만들지 않는다. 인용은 보도된 표현 그대로다
  (장윤정 댓글의 "고마와요", "코라쓰"는 원문 표기).
- **얼굴 없음:** 픽셀 스프라이트는 눈을 그리지 않는다. 장윤정도 같은 방식의 스프라이트로만.
- **로고 없음:** 유튜브·SNS 로고, 방송사 로고 없이. 댓글은 일반적인 말풍선/카드로.
- **가사 없음:** 메들리 곡은 제목과 원곡 가수 이름만. 노래방 가사 자리에는 이 영상의 자막(사실)만 흐른다.
- 곡 번호 "0918"은 실제 노래방 번호가 아니라 영상이 올라온 날짜(9월 18일)다. 화면에 그렇게 밝힌다.

## 도구 (`src/karaoke.js`)

- `sprite(x, y, px, { t, hair, outfit, trim, pose, mic, long, flip, bob })` — (x, y)는 발밑, px는 픽셀 한 칸 크기(10~16).
  pose: stand, sing, sway, cheer, clap, dance, bow
- `karaokeBg(t, { top, mid, low, moon, moonX, moonY, moonR, sea, seaY })` 노래방 배경(보름달, 픽셀 바다와 달빛 길, 별)
- `tinsel(t, x, y, w, h, colors)` 반짝이 커튼, `ledDigits(txt, x, y, h, color, { align })` 7세그먼트 LED
- `kLine(t, t0, t1, text, { y, size, fill, hold })` 노래방 가사처럼 t0→t1 동안 왼쪽부터 색이 채워지는 자막
- `kTitle(t, t0, t1, title, lines, { y, size, colors })` 곡 제목 화면, `kBanner(t, t0, t1, text, { y, size, bg })` 위쪽 자막 띠
- `pixelFirework(t, t0, x, y, r, color)`, `pixelHeart(x, y, px, color)`, `bend(t, t0, x, y, w, color)` 꺾기 곡선,
  `viewCounter(t, t0, value, suffix, x, y, size)`
- `SONG.tune` 에 반주 멜로디 음표(t, dur, midi)가 있다. 긴 음표마다 `bend()` 를 그려 꺾기를 보여 주면 좋다.
- core.js 의 `camBegin/camEnd`, `shakeXY`, `kf`, `pulse`, `hop`, `beatOf`, `flash`, `confetti`, `sunburst`.

인물은 가운데(y 900~1450), 위쪽 띠 자막은 y 250~450, **가사 자막(kLine)은 y 1450~1600**(쇼츠 UI가 덮는 맨 아래 300px 위).

## 3 · 선곡표 (`z3_medley.js`, 21.82 – 36.36)
