# 오늘도 수고했어 · 스토리보드

## 아이디어

마흔 넘은 아빠의 하루. 알람보다 먼저 깨는 새벽부터 만원 지하철, 부장님의 한숨, 결재 도장, 계산기,
야근, 막차까지. 무겁지만 짠하게 웃긴 톤으로 간다. 브리지에서 기타 치던 스무 살의 자신을 떠올리며
거울 속 아저씨를 낯설어하지만, 현관문을 열자 아이가 "아빠!" 하고 달려온다. 그 한마디로 조가 한 음
올라가고, 마지막 후렴은 주말의 가족이다. 마지막 장면은 소파에서 아이들과 함께 잠든 아빠, 그리고
불 켜진 수많은 창문. 창문마다 누군가의 아빠가 있다.

**모든 샷의 규칙:** 화면 안에서 무언가가 *일어난다*. 가사를 글자로 반복하지 않는다(카라오케가 한다).
효과음 글자(삐—! / 짠! / 쾅! / 아이고)는 가끔만 쓴다. 슬픈 장면도 작은 개그 하나는 품는다.

## 등장인물 (`src/family.js`, 그리고 공용 `../src/cast.js`)

| 누구 | 호출 | 생김새 |
|---|---|---|
| **아빠** | `person(x, y, s, { role: 'dad' })` | 짧은 머리에 관자놀이가 희끗, 턱 그림자, 살짝 나온 배, 회색 정장·파란 넥타이, 갈색 서류가방 (`briefcase`) |
| 엄마 | `role: 'mom'` | 단발, 분홍 카디건 |
| 막내 (6살 아들) | `role: 'child'` | 노란 공룡 티셔츠, 파란 바지, 바보털 |
| 첫째 (고등학생 딸) | `kid(x, y, s, { who: 'pony' })` | 첫 번째 뮤비의 포니테일 교복 |
| 부장님 | `role: 'boss'` | 대머리, 콧수염, 남색 정장, 빨간 넥타이, 배가 크다 |
| 동료 | `role: 'coworker'` | 안경, 사원증 |
| 스무 살의 아빠 | `role: 'young'` | 더벅머리, 빨간 ROCK 티셔츠, 기타 (`guitar`) |

소품: `briefcase`, `sojuGlass`, `sojuBottle`, `guitar` (family.js), 그 밖에 `../src/props.js` 전부.

## 흐름

- **팔레트:** 새벽 남색·회청색 → 출근길 차가운 회색과 연한 해 → 사무실 형광 민트·회색 → 포장마차 주황 → 밤 남색과 가로등 → 막차 보라 → 브리지 세피아(회상) → 현관의 따뜻한 노랑 → 마지막 후렴 쨍한 주말 하늘 → 밤의 수많은 창문 → 종이색 엔딩
- 템포는 100 BPM (박 0.6초, 마디 2.4초). 첫 번째 뮤비보다 샷을 조금 길게, 카메라를 조금 느리게.
- 후렴의 "(수고했)**어**" 에 히트: 50.40 / 60.00 / 98.40 / 108.00 / 141.60 / 151.20. "잔"에 잔 부딪히는 소리: 61.80 / 109.80 / 153.00.
