# 쇼츠 · "야호, 1위" (리센느 이야기)

세로 1080×1920, **52.5초**. 발매 1년 11개월 만에 멜론 1위에 오른 "러브 어택"의 역주행 이야기.

빌리 아일리시 쇼츠와 **구조가 다르다.** 그쪽은 시간 순서대로 가는 4막이었다. 이쪽은 **결말에서 시작해 되감는다.**
1위 소식이 온 밤(알람)으로 열고, VHS로 2024년까지 되감은 뒤, **순위 카운터(904위 → 1위)** 를 게임 점수처럼
화면 위에 띄워 올라가는 과정을 보여 주고, 다시 그 밤으로 돌아와 끝난다.

**캐릭터도 다르다.** 키 큰 역광 애니 인물 대신 2.5등신 **치비 5인조**를 쓴다. 파스텔 스티커 그림체(흰 오려낸 테두리),
하트, 하프톤 점, 게임 HUD.

## 원칙

- **사실만:** 화면 글자는 아래 표 그대로 쓴다. 새 사실, 숫자, 인용을 만들지 않는다. 인용 두 개는 1위 직후 라이브에서
  멤버들이 한 말이다(SBS 연예뉴스, 네이트 연예 등 보도).
- **얼굴 없음:** 실존 인물이라 눈을 그리지 않는다. 앞모습은 두꺼운 앞머리가 눈을 가리고 작은 입선과 볼터치만 보인다.
  눈물은 앞머리 밑에서 흐른다. 다섯 명의 머리 모양과 옷 색은 서로 구분하려는 것일 뿐 특정 멤버를 흉내 내지 않는다.
  멤버를 한 명씩 지목하는 장면(원이의 유튜브 등)에서도 화면 속 인물은 누구인지 특정하지 않는다.
- **로고·상표 없음:** 멜론·유튜브 로고, 앨범 표지, 음악방송 로고, 실제 트로피 디자인을 쓰지 않는다. 멜론은 글자
  "MELON TOP100"만, 동영상 사이트는 일반적인 녹화 화면(● REC), 트로피는 일반적인 별 달린 컵.
- **음악:** 리센느의 음원은 쓰지 않는다. 배경음악은 첫 번째 뮤비 〈고딩 라이프〉의 앞 28마디(시계 소리 인트로, 알람,
  1절, 프리코러스, 첫 후렴)를 보컬 없이 연주한 오리지널이다.

## 도구 (`src/pop.js`)

- `chibi(x, y, s, { t, look: 0..4, view: 'front'|'back', pose, mouth, tears, bob, sticker, flip })`
  - pose: stand, jump, run, wave, cry, hug, sleep, sit, bow, cheer
  - mouth: smile, open, o, wobble, flat
- `squad(cx, y, s, { spread, poses: [...], view, depth, ... })` 다섯 명을 한 줄로 세운다.
- `rankHUD(t, rank, { y, label, flash })` 게임 점수판처럼 생긴 순위 카운터.
- `popTag(t, t0, t1, text, { size, y, colors, bgs })` 스티커 말풍선 자막(위쪽 1/3), `popSub(...)` 그 아래 작은 자막.
- `bubble(x, y, text, size)` 말풍선, `hearts()`, `halftone()`, `pastelBg()`, `phone(x, y, s, fn)` 화면을 그리는 휴대폰,
  `vhs(t, k, { label })` 되감기 노이즈, `burstStar()`.
- core.js 의 `camBegin/camEnd`, `shakeXY`, `kf`, `pulse`, `hop`, `confetti`, `speedLines`, `sunburst`, `flash`.

인물·주요 사물은 가운데(y 700~1650)에, 자막은 위쪽(y 250~750)에 둔다. 아래 300px에는 중요한 것을 두지 않는다.
