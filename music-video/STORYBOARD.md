# 고딩 라이프 · 스토리보드

## 아이디어

평범한 고등학생의 하루하루가 한 곡 안에서 한 해로 흘러간다. 새벽 알람으로 시작해 등교, 졸린 1교시,
급식 전력 질주, 야자, 성적표, 다시 아침. 브리지에서 D-day 숫자가 줄어들고 어른들의 질문이 커지며 잠깐
멈칫하지만, 시험이 끝나는 순간 조가 한 음 올라가며 모든 게 터진다. 마지막은 세 친구의 폴라로이드.

**모든 샷의 규칙:** 화면 안에서 무언가가 *일어난다*. 인물이 뭔가를 하고, 뭔가가 부서지고, 변하고,
날아가고, 떨어진다. 가사를 글자로 반복하지 않는다(카라오케가 이미 한다). 큰 효과음 글자
(삐비빅! / 세이프! / 쿵!)는 드물게, 꼭 필요할 때만.

## 등장인물 (`src/cast.js`)

| 누구 | 생김새 | 역할 |
|---|---|---|
| **나** (`who: 'me'`) | 까만 짧은 머리, 안 눕는 바보털, 노란 가방 | 노래의 "나". 거의 모든 샷의 주인공 |
| **포니** (`who: 'pony'`) | 갈색 포니테일, 리본, 치마 | 활발한 친구. 제일 먼저 뛰고 제일 크게 웃는다 |
| **안경** (`who: 'glasses'`) | 동그란 안경, 단정한 가르마 | 차분한 친구. 쪽지, 문제집, 성적표 담당 |
| 선생님 (`adult kind: 'teacher'`) | 올린 머리, 안경, 올리브색 카디건 | 1교시, 야자 감독 |
| 선도부 선생님 (`kind: 'guard'`) | 파란 트레이닝복, 모자, 호루라기 | 교문 |
| 엄마·아빠·이모 (`mom`/`dad`/`aunt`) | | 브리지에서 커다란 실루엣으로 "꿈이 뭐니?" |

## 흐름

- **팔레트 흐름:** 새벽 남색 → 아침 하늘색·주황 → 교실 크림색 → 점심 노랑·민트 → 저녁 분홍 → 야자 남색과 형광등 → 다시 아침 → 체육대회 초록·하늘 → 브리지 짙은 보라·별 → 시험장 회색 → 폭발하는 금빛 일출 → 따뜻한 노을 → 종이색 엔딩
- **챕터 경계**는 붓 와이프(`wipe`)나 동기가 있는 전환(분필이 날아와 화면을 덮음, 문이 열림, 종이가 화면을 덮음, 플래시)으로 넘긴다.
- **카메라는 늘 움직인다:** 천천히 밀고, 비트에 흔들고, 휙 돌린다.
- **비트에 맞춘다:** 중요한 동작은 박자 위에 떨어진다. 코러스의 "프!" (38.18 / 45.45 / 74.55 / 81.82 / 107.27 / 114.55 / 125.45) 는 큰 히트.
