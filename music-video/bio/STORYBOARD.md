# 작은 방에서 · 빌리 아일리시 이야기 (스토리보드 v2)

## 한 줄

**침실에서 시작한 노래가 세상에 닿기까지. 그리고 지금 어느 작은 방에서 첫 노래를 만들고 있을 당신에게.**

v1 은 성취를 늘어놓은 목록이었다. v2 는 **한 사람의 이야기**다. 춤을 사랑하던 소녀가 부상으로 춤을
잃고, 남은 노래로 세상에 나가고, 빛 뒤의 아픔을 숨기지 않고, 정상에서 "침실에서 음악 만드는 모든
아이들"에게 말을 건넨다. 마지막 장면은 **다른 누군가의 작은 방**이다. 보는 사람이 주인공이 되며 끝난다.

## 원칙 (v1 과 같음, 더 엄격하게)

- **사실만.** 내레이션과 자막은 아래 표의 문구를 **한 글자도 바꾸지 않고** 쓴다. 새 사실, 숫자, 인용을 만들지 않는다.
  인용은 딱 하나(피니어스의 2020 그래미 수상 소감)이며, 번역문과 출처를 함께 표시한다.
- **얼굴 없음.** 빌리와 피니어스는 얼굴 없는 실루엣(`silhouette()`)이거나, 손·뒷모습·그림자·물건으로만 나온다.
  아이 시절도 마찬가지(작은 실루엣).
- **로고·상표·앨범 표지·포스터 없음.** 그래미는 금색 축음기, 오스카는 금색 별 트로피.
- 아픔(우울증, 투렛 증후군)은 **자막 그대로, 담담하게**. 자해나 구체적 증상은 그리지 않는다.

## 이번엔 "실감 나게"

`src/cinema.js` 가 모든 프레임에 레터박스(2.35:1), 블룸(빛 번짐), 색 보정, 필름 그레인, 비네트를 입힌다.
그 위에서 챕터는 **영화처럼** 찍는다.

- **빛이 주인공:** 창으로 들어오는 빛줄기(`godRays`), 빛 속의 먼지(`dust`), 램프의 따뜻한 원, 모니터의 푸른빛, 무대 조명.
- **깊이:** 3~4겹 레이어. 먼 배경은 `withBlur(6~12)` 로 흐리게, 가까운 전경(커튼, 기둥, 관객 머리)도 흐리게. 초점은 가운데 하나.
- **카메라:** 모든 샷에 천천히 밀기·당기기·패닝 + `handheld(t)` 의 미세한 흔들림. 컷은 동기 있게(빛, 소리, 움직임으로).
- **질감:** 평면 단색 대신 그라디언트, 부드러운 그림자, 반사(바닥, 유리). 카툰 외곽선(ink stroke)은 쓰지 않거나 아주 얇게.
- **글자:** 내레이션은 `narration()` (명조체, 한 글자씩 스며듦). 사실 자막은 `caption()`/`yearTag()` 이며 레터박스 안에 들어간다.
  화면 안 이미지 영역은 y 132–948.
- **음악:** 피아노·스트링 발라드(오리지널). 절은 피아노만 흐르고, 후렴 강박(50.40 / 60.00 / 98.40 / 108.00 / 141.60 / 151.20)에서 감정이 커진다. 138.60 에 한 박 정적, 139.20 에 조가 오르며 폭발한다.

## 도구

`narration(t, t0, t1, text, { y, size })`, `quote(t, t0, t1, text, who)`, `caption(t, t0, t1, 제목, 부제)`,
`yearTag(t, t0, '2015')`, `bigFact(t, t0, t1, text, x, y, size)`, `silhouette(x, y, s, { t, hair, pose, glow, body })`,
`withBlur(px, fn)`, `godRays(t, x, y, angle, spread, len, color, alpha)`, `dust(t, x, y, w, h, n, color)`,
`bokeh(t, n, colors, y0, y1, blur)`, `handheld(t, amt)`, `flare(x, y, size, color)`. 색 `BIO.*`.
시기별 머리색(실루엣): 어린 시절·2015 `#6B4A3A`(갈색), 2016–17 `#5B8CFF`(파랑), 2019–20 `#7ED321`(초록), 2021 `#E8D08A`(금발), 2022 이후 `#1A1320`.
