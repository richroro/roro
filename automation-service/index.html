자주 묻는 질문

비개발자인데도 사용할 수 있나요?

네. 대부분 "버튼 클릭" 또는 "정해진 시간에 자동 실행"처럼 만들어 드립니다. 사용법도 문서와 함께 안내해 드리기 때문에 코딩을 몰라도 됩니다.

정확한 비용은 어떻게 정해지나요?

업무의 복잡도, 다루는 데이터 양, 연동해야 할 서비스 개수에 따라 달라집니다. 문의를 남겨주시면 무료로 진단 후 정확한 견적을 알려드립니다. 견적 확인 후 진행 여부를 결정하시면 됩니다.

만들고 난 뒤에 문제가 생기면요?

납품 후 일정 기간 무상 수정을 지원하며, 사이트 구조 변경 등 지속적인 관리가 필요한 경우 월 유지보수 계약도 가능합니다.

결과물은 어떤 형태로 받나요?

실행 파일 또는 스크립트, 사용 설명서, 필요 시 소스코드까지 전달해 드립니다. 원하시면 서버에 올려 자동 실행되도록 세팅해 드립니다.

어떤 업무는 자동화가 안 되나요?

규칙이 명확한 반복 업무는 대부분 자동화됩니다. 반대로 매번 사람의 판단이 크게 필요한 일은 부분 자동화(초안 생성 등)로 도와드립니다. 우선 편하게 문의 주세요.
