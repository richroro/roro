# 카페24 앱스토어 등록 체크리스트

## 0. 준비물
- 사업자 등록 (개인 판매자는 월 정산 한도 200만 원)
- 카페24 개발자센터 계정, 파트너센터 판매자 약관 동의
- HTTPS 도메인 (앱 URL·Redirect URL·웹훅 모두 https 필수)
- 개인정보 처리방침 페이지 URL (회원 ID·주문 상태를 조회하므로 필수)

## 1. 개발자센터 앱 생성
| 항목 | 값 |
|---|---|
| 앱 이름 | AI 답변 도우미 |
| 앱 유형 | 관리자 앱 (Admin API) |
| 앱 URL | `https://<도메인>/app/launch` |
| Redirect URL | `https://<도메인>/oauth/callback` |
| 권한(scope) | `mall.read_community`, `mall.write_community`, `mall.read_product`, `mall.read_order`, `mall.read_store` |
| 웹훅 | `게시글 등록(90033)`, `앱 삭제(90077)`, `앱 만료(90078)`, `앱 결제(90157)` → `https://<도메인>/webhooks/cafe24` |

권한 최소화 근거 (심사 시 설명용):
- `read_community/write_community`: 게시판 목록·미답변 글 조회, 답변글·댓글 등록
- `read_product`: 문의 대상 상품 정보(설명·옵션·품절)로 답변 근거 확보
- `read_order`: 회원 문의의 "배송 언제 오나요"에 본인 주문 상태로 답변. 작성자 회원 ID로만 조회하며 주소·연락처·결제수단은 사용하지 않음
- `read_store`: 설치 시 쇼핑몰 이름 자동 입력

## 2. 스토어 상품 페이지
- 카테고리: 고객 대응(CS) / AI
- 한 줄 소개: "상품문의·후기 답변, AI가 초안 쓰고 운영자는 확인만"
- 스크린샷 4장: ① 답변 대기함(초안·확신도·근거) ② 설정(정책 입력) ③ 게시 완료 화면 ④ 대시보드
- 요금제: 무료(월 30건) / 스타터 29,000원(월 300건) / 프로 89,000원(월 1,000건, 자동 게시) — `src/plans.js`와 일치시킬 것
- 결제 방식: 카페24 과금 API 정기결제(`automatic_payment: T`)

## 3. 심사 대비 점검
- [ ] 앱 실행 URL HMAC 검증 (`verifyLaunchRequest`) — 서명 불일치·timestamp 초과 시 403
- [ ] OAuth state 서명·만료 검증, code 1회 사용
- [ ] 토큰은 서버 DB에만 저장, 브라우저에는 서명 쿠키(세션)만
- [ ] 웹훅 서명 검증(`X-Cafe24-Hmac-Sha256`) 실패 시 401
- [ ] 앱 삭제 웹훅(90077) 수신 시 토큰·설정·초안 즉시 삭제
- [ ] 개인정보: 주문 조회는 작성자 본인 회원 ID로 제한, AI 전달 필드 최소화(`summarizeOrders`)
- [ ] AI 오답 방지: 기본 승인형, 정책 밖 질문은 사람 확인, 자동 게시는 프로+조건부
- [ ] 호출 한도 준수: 429 시 Retry-After 백오프, 한 번의 동기화 초안 상한(`MAX_DRAFTS_PER_SYNC`)
- [ ] 장애 시 사용자 안내 페이지(401/403/500 한국어 화면)
- [ ] 이용약관·개인정보 처리방침·문의 채널 링크를 앱 하단에 추가 (운영 전 TODO)
