# 업무 자동화 전문가 등록 콘텐츠 (크몽 · 숨고 · 라우드소싱)

> 포지셔닝: **엑셀/데이터 수집 자동화** · **진입가 5만~15만** · **신규(실적 없음, 솔직 포지셔닝)**
> 원칙: 후기·경력 지어내지 않기. "합리적 가격 + 빠른 소통 + 실제 작동하는 결과물"로 신뢰 확보.

---

## 0. 공통 자산 (모든 플랫폼 공용)

### 브랜드/닉네임 후보
- **오토밥** (오토메이션 + 밥값하는 자동화)
- **데이터김비서** (데이터 잡무를 대신하는 비서)
- **엑셀손절연구소** (엑셀 노가다를 손절시켜 드립니다)
- **클릭한번** (한 번 세팅, 매일 자동)

### 한 줄 소개 (프로필 헤드라인)
> 반복되는 엑셀·데이터 정리, 매번 손으로 하지 마세요. 한 번 세팅하면 매일 자동으로 돌아갑니다.

### 짧은 자기소개 (2~3문장)
> 반복적인 엑셀 정리, 웹사이트에서 데이터 긁어오기, 여러 파일 합치기처럼 "사람이 하기엔 아깝고 지치는" 업무를 자동화해 드립니다. 파이썬 기반으로 실제 작동하는 스크립트를 만들어 드리고, 비전문가도 버튼 한 번으로 쓸 수 있게 정리해 드립니다. 신규 입점이라 합리적인 가격과 빠른 소통으로 승부합니다.

### 신규 판매자 신뢰 확보 문구 (실적 없을 때 솔직 카피)
> 아직 이 플랫폼에서의 거래 실적은 없지만, 그만큼 **첫 고객님께 진심입니다.** 결과물이 마음에 드실 때까지 수정해 드리고, 작동 영상/화면으로 결과를 직접 확인시켜 드립니다.

### 대표 서비스 3종 (제공 가능 범위)
1. **웹 데이터 수집 자동화** — 특정 사이트에서 상품/가격/목록/뉴스 등을 자동으로 긁어 엑셀로 저장
2. **엑셀 반복작업 자동화** — 여러 파일 합치기, 서식 정리, 중복 제거, 집계·리포트 자동 생성
3. **정기 실행 세팅** — 매일/매시간 자동으로 돌아가게 스케줄 등록까지 세팅

## 1. 크몽 (Kmong) — 서비스 상품 등록

### 카테고리
- 대분류: **프로그래밍·테크**
- 소분류: **자동화·크롤링** (또는 "데이터 수집/크롤링", "업무 자동화")

### 서비스 제목 후보 (택1, 크몽은 임팩트 중요)
1. `반복되는 엑셀·데이터 정리, 파이썬으로 자동화해 드립니다`
2. `웹사이트 데이터 자동 수집(크롤링)해서 엑셀로 정리해 드립니다`
3. `매일 하던 엑셀 노가다, 버튼 한 번으로 끝내드립니다`

> 추천: 1번(범용) 또는 2번(수요 큼). 서비스는 2개 따로 등록해도 좋음(크롤링 / 엑셀자동화).

### 가격 패키지 (3단 구성)

| 구분 | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 패키지명 | 간단 자동화 | 표준 자동화 | 맞춤 자동화 |
| 가격 | **50,000원** | **90,000원** | **150,000원** |
| 설명 | 단순 반복작업 1건 자동화 | 조건·가공이 있는 자동화 + 엑셀 정리 | 수집→가공→리포트까지 + 정기 실행 세팅 |
| 데이터 소스/시트 수 | 1개 | 최대 3개 | 최대 5개 |
| 결과물 | 실행 스크립트 + 사용법 | 스크립트 + 엑셀 자동 출력 | 스크립트 + 리포트 + 스케줄 자동실행 |
| 수정 횟수 | 1회 | 2회 | 3회 |
| 작업일 | 3일 | 4일 | 5일 |

### 상세 설명 (본문 복붙용)

```
■ 이런 분께 딱 맞습니다
- 매일 같은 사이트에 들어가 가격/목록/뉴스를 복붙하고 계신 분
- 엑셀 여러 개를 매번 손으로 합치고 정리하시는 분
- 중복 제거, 서식 통일, 집계 리포트를 반복해서 만드시는 분
- "이거 자동으로 안 되나?" 싶은 잡무가 있는 분

■ 무엇을 해드리나요
1) 웹 데이터 자동 수집 — 원하는 사이트에서 필요한 정보만 뽑아 엑셀로 저장
2) 엑셀 반복작업 자동화 — 파일 합치기 / 정리 / 중복제거 / 집계 / 리포트
3) 정기 실행 세팅 — 매일·매시간 자동으로 돌아가게 스케줄 등록

■ 진행 방식
1. 채팅으로 "어떤 작업을 매번 반복하는지" 알려주세요 (스크린샷 환영)
2. 자동화 가능 여부와 범위를 무료로 알려드립니다
3. 결제 후 스크립트 제작 → 작동 화면/영상으로 확인 → 전달

■ 결과물
- 바로 실행 가능한 프로그램(스크립트)
- 비전문가도 따라 하는 사용 설명서
- 작동 확인 영상/캡처

■ 신규 입점 안내
아직 크몽 거래 실적은 없습니다. 그만큼 첫 고객님께 진심으로 임하며,
결과가 마음에 드실 때까지 수정하고 작동 화면으로 직접 확인시켜 드립니다.
합리적인 가격과 빠른 응답(보통 수 시간 내)으로 보답하겠습니다.

■ 안내
- 로그인/결제/캡차가 필요한 사이트, 저작권·약관상 수집 금지 사이트는 진행이 어려울 수 있습니다.
  먼저 채팅으로 대상 사이트를 알려주시면 가능 여부를 확인해 드립니다.
```

### 태그 (검색 노출용)
`엑셀자동화` `크롤링` `데이터수집` `파이썬` `업무자동화` `웹스크래핑` `엑셀매크로` `데이터정리`

### 자주 묻는 질문 (FAQ 섹션)
- **Q. 어떤 사이트든 다 가능한가요?** → 대부분 가능하지만 로그인·캡차·약관상 금지 사이트는 제한될 수 있어 사전 확인이 필요합니다.
- **Q. 프로그램 없이도 쓸 수 있나요?** → 네, 버튼(또는 더블클릭)으로 실행되게 정리해 드립니다.
- **Q. 나중에 사이트가 바뀌면요?** → 유지보수는 별도 협의로 도와드립니다.

## 2. 숨고 (Soomgo) — 고수 등록

### 서비스 분야 선택 (검색 시)
- "프로그램 개발" / "데이터 크롤링" / "엑셀 자동화" / "업무 자동화" 관련 카테고리 선택
- 세부: 웹 크롤링, 엑셀·매크로, 파이썬 개발

### 고수 자기소개 (프로필 본문)

```
안녕하세요. 반복적인 엑셀·데이터 업무를 자동화해 시간을 돌려드리는 자동화 전문가입니다.

[이런 일을 대신해 드립니다]
· 웹사이트 데이터 자동 수집 (상품/가격/목록/뉴스 등 → 엑셀 저장)
· 엑셀 반복작업 자동화 (파일 합치기, 정리, 중복 제거, 집계 리포트)
· 매일·매시간 자동 실행 세팅

[이렇게 일합니다]
· 먼저 어떤 작업을 반복하는지 듣고, 자동화 가능 여부를 솔직하게 알려드립니다
· 실제 작동하는 결과물을 만들고, 작동 화면으로 직접 보여드립니다
· 비전문가도 쓸 수 있게 사용법을 정리해 드립니다

[가격]
· 간단 자동화 5만원부터 / 표준 9만원 / 맞춤 15만원
· 범위에 따라 견적 조율 가능합니다

신규로 시작하는 만큼 합리적인 가격과 빠른 소통으로 첫 고객님께 최선을 다하겠습니다.
편하게 요청 주세요. 자동화 가능 여부 상담은 무료입니다.
```

### 견적 요청 응답 템플릿 (숨고는 견적 경쟁이라 첫 메시지가 중요)

```
안녕하세요, 요청 주셔서 감사합니다.
말씀하신 [작업 내용]은 자동화 가능해 보입니다.

· 예상 범위: (예) OO사이트에서 매일 목록 수집 → 엑셀 자동 정리
· 예상 금액: OO만원 (작업일 O일)
· 진행: 결제 전 자동화 가능 여부/샘플을 먼저 확인시켜 드립니다

정확한 견적을 위해 아래만 알려주시면 바로 답변드릴게요.
1) 대상 사이트/파일 (스크린샷 환영)
2) 매번 반복하는 작업 순서
3) 원하는 결과물 형태 (엑셀? 자동 실행?)
```

## 3. 라우드소싱 (Loudsourcing) — 외주마켓 전문가 등록

> 라우드소싱은 디자인 공모전 색이 강하지만 "외주마켓"에 IT·자동화 전문가 등록 가능.
> 포트폴리오/역량 중심으로 작성.

### 전문가 프로필 소개

```
[전문 분야] 업무 자동화 · 데이터 수집(크롤링) · 엑셀 자동화

반복되는 데이터·엑셀 업무를 파이썬 기반으로 자동화합니다.
사람이 매일 손으로 하던 일을 '한 번 세팅, 매일 자동'으로 바꿔드립니다.

[제공 서비스]
· 웹 데이터 자동 수집 및 엑셀 저장
· 엑셀 파일 병합/정리/집계 자동화
· 정기 자동 실행(스케줄) 세팅

[강점]
· 실제 작동하는 결과물 + 작동 화면 검증
· 비전문가도 쓰는 사용법 정리
· 합리적 가격, 빠른 소통

[가격 가이드] 5만원~ (범위별 협의)
```

### 포트폴리오로 올릴 항목 (실적 없을 때 — 데모/샘플로 대체)
> 실거래 실적이 없으므로, **본인이 직접 만든 자동화 데모**를 포트폴리오화하면 됩니다.
1. **"뉴스 자동 수집 → 엑셀 정리" 데모** — 실행 전/후 화면 캡처 + 30초 작동 영상
2. **"엑셀 여러 파일 자동 병합" 데모** — Before(파일 5개) / After(통합 시트) 캡처
3. **"매일 자동 실행" 데모** — 스케줄 등록 화면 + 자동 생성된 결과 파일 캡처

> ⭐ 팁: 위 데모 3개는 회원님이 이미 보유한 스킬(데이터 수집/엑셀)로 30분이면 만들 수 있습니다.
> 이게 신규 판매자에게 후기보다 강력한 신뢰 자산입니다.

## 4. 등록 순서 체크리스트 (회원님이 직접 하실 일)

- [ ] 크몽/숨고/라우드소싱 각 사이트에서 **회원가입 + 전문가/판매자 전환**
- [ ] 프로필 사진 등록 (얼굴 or 깔끔한 로고 — 신뢰도 ↑)
- [ ] 위 콘텐츠 **복붙**하여 서비스/프로필 작성
- [ ] **데모 3종** 제작해 대표 이미지/포트폴리오로 등록  ← 실적 대체 핵심
- [ ] 크몽: 3단 가격표 그대로 입력
- [ ] 게시 → 첫 문의 오면 위 응답 템플릿 사용

## 5. 신규 판매자 초반 실적 만드는 법 (선택)
- 첫 3건은 **의도적으로 저가/무료 샘플**로 후기 확보 (지인·커뮤니티 활용)
- 후기 3개만 쌓이면 진입가 → 표준가로 인상
- 각 거래마다 "작동 영상"을 남겨 다음 고객에게 보여주기
```
