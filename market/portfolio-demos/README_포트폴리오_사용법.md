# 포트폴리오 데모 3종 — 사용 & 캡처 가이드

크몽·숨고·라우드소싱에 올릴 **작동 증거(포트폴리오)** 3종입니다.
실적/후기가 없을 때, 이 "실제 작동 화면·영상"이 별점보다 강력한 신뢰 자산이 됩니다.

> 공통 준비: Python 3 + openpyxl 필요 (`pip install openpyxl`)

---

## 데모 1) 뉴스 자동 수집 → 엑셀 정리
- 폴더: `demo1_news/`
- 실행: `python news_to_excel.py`
- 결과: `뉴스_수집결과_날짜.xlsx` (실제 언론사 RSS에서 최신 기사 자동 수집)

**캡처 포인트**
- 실행 콘솔 화면 ("총 20건 수집 완료")
- 생성된 엑셀 (제목/링크/발행일이 서식 있게 정리된 표 + 요약 시트)
- 30초 영상: 실행 → 엑셀 자동 생성되는 과정

**어필 문구 예시**
> "매일 뉴스 사이트를 돌며 복붙하던 일을 명령어 한 줄로 끝냅니다. 원하는 사이트·항목으로 맞춤 제작해 드립니다."

---

## 데모 2) 엑셀 여러 파일 자동 병합 + 집계 리포트  ⭐ 추천
- 폴더: `demo2_excel_merge/`
- 실행:
  1. `python 1_make_sample_files.py`  → 지점별 매출 파일 5개 생성 (**Before**)
  2. `python 2_merge_and_report.py`   → 통합 리포트 자동 생성 (**After**)
- 결과: `통합매출_리포트.xlsx` (통합원본 / 지점별집계+막대차트 / 상품별집계)

**캡처 포인트 (Before/After 대비가 핵심)**
- Before: `input_files/` 폴더에 흩어진 엑셀 5개
- After: 하나로 합쳐지고 차트까지 들어간 통합 리포트
- 이 대비 한 장이 가장 설득력 높음

**어필 문구 예시**
> "지점별·월별로 흩어진 엑셀 수십 개도 클릭 한 번에 통합하고, 집계 리포트와 차트까지 자동으로 만듭니다. 파일이 5개든 50개든 동일합니다."

---

## 데모 3) 매일 자동 실행 (스케줄 세팅)
- 폴더: `demo3_scheduler/`
- 실행: `python daily_report.py` (수동 테스트) / `run_daily.bat` (스케줄 등록용)
- 결과: `auto_reports/일일리포트_날짜.xlsx` + `실행로그.txt`
- 등록법: `README_스케줄러_등록법.md` 참고

**캡처 포인트**
- 작업 스케줄러에 등록된 "매일 오전 8시" 작업 화면
- 날짜별로 자동으로 쌓인 리포트 파일들
- `실행로그.txt`의 자동 실행 이력

**어필 문구 예시**
> "한 번 세팅하면 매일 정해진 시간에 사람 손 없이 리포트가 자동 생성됩니다. 컴퓨터만 켜두시면 됩니다."

---

## 플랫폼별 활용
- **크몽**: 데모 2의 Before/After 캡처를 대표 이미지(썸네일)로. 상세페이지에 3종 모두.
- **숨고**: 프로필 포트폴리오에 3종 캡처 + 각 30초 영상.
- **라우드소싱**: 포트폴리오 항목 3개로 각각 등록.

## 촬영 팁
- 화면 녹화: 윈도우 `Win + G`(Xbox Game Bar) 또는 무료 OBS
- 영상은 30초 이내, 실행→결과까지 한 흐름으로
- 엑셀은 열어서 **차트/서식이 보이게** 캡처 (밋밋한 표보다 설득력 ↑)
