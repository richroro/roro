# 데모 3) 매일 자동 실행 세팅법 (윈도우 작업 스케줄러)

이 데모는 "한 번 등록하면 매일 정해진 시간에 자동으로 리포트가 생성된다"를 보여줍니다.

## 등록 방법 (윈도우 작업 스케줄러)

1. 시작 메뉴 → **작업 스케줄러**(Task Scheduler) 실행
2. 오른쪽 **기본 작업 만들기** 클릭
3. 이름: `일일 리포트 자동생성` → 다음
4. 트리거: **매일** 선택 → 시간 지정 (예: 오전 8시) → 다음
5. 동작: **프로그램 시작** → 찾아보기로 이 폴더의 `run_daily.bat` 선택
6. 마침 → 완료

이제 매일 오전 8시에 `auto_reports/` 폴더에 `일일리포트_날짜.xlsx`가 자동으로 쌓입니다.
사람이 컴퓨터만 켜두면 아무 조작 없이 결과가 만들어집니다.

## 즉시 테스트
작업 스케줄러 목록에서 만든 작업을 우클릭 → **실행**을 누르면
지금 바로 리포트가 생성되는 걸 확인할 수 있습니다.

## 포트폴리오 캡처 포인트
- 작업 스케줄러에 등록된 작업 화면 (트리거: 매일 오전 8시)
- `auto_reports/` 폴더에 날짜별로 쌓인 파일들
- `실행로그.txt` — 자동 실행 이력이 시간과 함께 기록됨
