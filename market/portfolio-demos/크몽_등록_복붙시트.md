# 크몽 서비스 등록 — 단계별 복붙 시트 (엑셀 자동화 / 시안 A 확정)

> 진행: 크몽 로그인 → 우상단 **판매자 전환**(안 돼 있으면) → **서비스 등록** 클릭 → 아래 순서대로 복붙
> 대표이미지: **thumb_A.png** (첫 번째 이미지로 업로드 = 카드 썸네일이 됩니다)

---

## STEP 1. 카테고리
- 대분류: **IT·프로그래밍**
- 소분류: **자동화·크롤링** (없으면 "데이터 크롤링" 또는 "업무 자동화 · 매크로")

## STEP 2. 서비스 제목  (그대로 복붙)
```
반복되는 엑셀·데이터 정리, 파이썬으로 자동화해 드립니다
```
> 40자 제한에 걸리면 축약본: `반복되는 엑셀 정리, 파이썬으로 자동화해 드립니다`

## STEP 3. 대표 이미지 / 동영상
1. **thumb_A.png 를 첫 번째로 업로드** ← 이게 목록 썸네일
2. 2~5번째 이미지로 포트폴리오 캡처 추가 (강력 추천):
   - 데모2 Before(파일 5개) 캡처
   - 데모2 After(통합 리포트+차트) 캡처
   - 데모1 뉴스 수집 엑셀 캡처
3. 동영상 있으면 30초 실행 영상 업로드

## STEP 4. 가격 (패키지 사용 = ON, 3단)

| 항목 | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 패키지명 | 간단 자동화 | 표준 자동화 | 맞춤 자동화 |
| 가격(원) | 50000 | 90000 | 150000 |
| 작업일 | 3 | 4 | 5 |
| 수정 횟수 | 1 | 2 | 3 |

**패키지 설명 (각 칸에 복붙)**
- STANDARD:
```
단순 반복작업 1건 자동화. 데이터 소스/시트 1개. 실행 스크립트 + 사용법 제공.
```
- DELUXE:
```
조건·가공이 있는 자동화 + 엑셀 자동 정리. 소스/시트 최대 3개. 스크립트 + 엑셀 자동 출력.
```
- PREMIUM:
```
수집→가공→리포트까지 + 정기 자동실행 세팅. 소스/시트 최대 5개. 스크립트 + 리포트 + 스케줄 자동실행.
```

## STEP 5. 서비스 설명 (상세 본문 — 통째로 복붙)
```
■ 이런 분께 딱 맞습니다
- 매일 같은 사이트에 들어가 가격/목록/뉴스를 복붙하고 계신 분
- 엑셀 여러 개를 매번 손으로 합치고 정리하시는 분
- 중복 제거, 서식 통일, 집계 리포트를 반복해서 만드시는 분
- "이거 자동으로 안 되나?" 싶은 잡무가 있는 분

■ 무엇을 해드리나요
1) 웹 데이터 자동 수집 — 원하는 사이트에서 필요한 정보만 뽑아 엑셀로 저장
2) 엑셀 반복작업 자동화 — 파일 합치기 / 정리 / 중복제거 / 집계 / 리포트
3) 정기 실행 세팅 — 매일·매시간 자동으로 돌아가게 스케줄 등록

■ 진행 방식
1. 채팅으로 "어떤 작업을 매번 반복하는지" 알려주세요 (스크린샷 환영)
2. 자동화 가능 여부와 범위를 무료로 알려드립니다
3. 결제 후 스크립트 제작 → 작동 화면/영상으로 확인 → 전달

■ 결과물
- 바로 실행 가능한 프로그램(스크립트)
- 비전문가도 따라 하는 사용 설명서
- 작동 확인 영상/캡처

■ 신규 입점 안내
아직 크몽 거래 실적은 없습니다. 그만큼 첫 고객님께 진심으로 임하며,
결과가 마음에 드실 때까지 수정하고 작동 화면으로 직접 확인시켜 드립니다.
합리적인 가격과 빠른 응답(보통 수 시간 내)으로 보답하겠습니다.

■ 안내
- 로그인/결제/캡차가 필요한 사이트, 저작권·약관상 수집 금지 사이트는 진행이 어려울 수 있습니다.
  먼저 채팅으로 대상 사이트를 알려주시면 가능 여부를 확인해 드립니다.
```

## STEP 6. 수정 및 환불 규정 (있으면 복붙)
```
- 수정: 패키지별 제공 횟수 내 무료 수정
- 추가 수정/기능 추가: 별도 협의
- 작업 시작(스크립트 제작 착수) 후에는 부분 환불만 가능합니다
```

## STEP 7. FAQ (Q/A 각각 입력)
1. Q `어떤 사이트든 다 가능한가요?`
   A `대부분 가능하지만 로그인·캡차·약관상 금지 사이트는 제한될 수 있어 사전 확인이 필요합니다.`
2. Q `프로그램 없이도 쓸 수 있나요?`
   A `네, 버튼(또는 더블클릭)으로 실행되게 정리해 드립니다.`
3. Q `나중에 사이트가 바뀌면요?`
   A `유지보수는 별도 협의로 도와드립니다.`

## STEP 8. 구매 시 필요한 정보 (구매자 요구사항)
```
1) 대상 사이트 주소 또는 엑셀 파일 (스크린샷 환영)
2) 매번 반복하는 작업 순서
3) 원하는 결과물 형태 (엑셀 저장? 자동 실행?)
```

## STEP 9. 태그 (하나씩 입력)
`엑셀자동화` `크롤링` `데이터수집` `파이썬` `업무자동화` `웹스크래핑` `엑셀매크로` `데이터정리`
